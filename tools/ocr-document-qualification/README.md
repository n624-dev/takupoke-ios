# Frozen independent complete-scope source comparison

This cohort is designed before inference, independently of school documents.
It contains all seventeen required classes and five days, with all eight periods
for normal/return and six for exam. Each of two already consumed fonts has all
three kinds. Source and body prefixes are newly invented; no renamed original,
original layout, source extraction or private PDF is used. The fonts are not new,
pretraining membership is unknown, and these results do not establish general
unseen-font accuracy. This is basic unmerged/unrotated layout qualification only.

Each matrix job generates exactly one fixed case and checks the protocol SHA,
source identities, full inventory and original app-byte guard. The reader sees
only the image-only PDF, ID, kind and hash; model input has no oracle or region
coordinates. Original PDFKit pixels, production raster/rules and physical cells
are acquired in a separate native research test, then unchanged raw V6 inference
the v5 measured class-column alternative and v6 fixed ASCII class specialist run
on both raster conditions. Original V6 and class specialist results remain separate;
expected class names never select model outputs.
Only after inference has completed does the separate quality-comparison process
read the cohort assertions. Before that, unit tests validate separately generated
fixture contracts, without passing their assertions to the reader.
Native Vision retains its 2048px contract and own original comparison coordinates.
V6's 4096 bound is a separate raster condition, not the same-pixel engine comparison.

The generic reader/comparator keep discovery6/444 as their default. Only explicit
`--cohort full-scope` selects this fixed protocol's one-case and full body-count
contract. All 17 class names are also asserted. Empty, unsupported or unassigned
ink is not hidden by correct body fields. Exact literals and own-score eligibility
are reported separately. Every one of the six jobs must finish; no cancelling,
cache, artifact, remote OCR, app/model manifest or Release changes.
