Run `TKPK_TEST_IOS=26 bash tools/test-manual-ui.sh` on an Apple SDK runner (27 is also supported). The unset `TKPK_MANUAL_CASE` requires all three exact XCTest completions; setting it to one declared method requires that method alone to pass. Missing, duplicate, skipped, failed or foreign method results refuse completion.

The release workflow runs each of the three manual cases separately on iOS 26 and 27, with a 35-minute job limit. The four ordinary UI jobs retain their 45-minute limit. Development distribution requires all thirteen checks from the same workflow, commit and attempt: distribution, native parsing, four ordinary UI jobs, six manual jobs and the unsigned iPhone build. The main publication gate requires the twelve checks preceding its own device build/publication job. Neither gate combines an earlier case result with a later attempt.

This tool does not create or dispatch a workflow. Termination diagnostics are off by default and require `TKPK_MANUAL_DIAGNOSTICS=1`; the bounded collector exports exact owned-app text reports, never screenshots or image attachments. Generated PDFs/images/projects are temporary and removed on exit. No PDF/font/image binaries are tracked. Host wrapper tests and Swift syntax checks do not establish actual Simulator success, OCR/model quality, physical-phone behavior or heavy-model inference cancellation.
