# Native Vision画像入力の限定診断

アプリ・Strict・入口・経路・採用条件は変更しない。研究比較と同じ、使用済みの独立架空PDFの
先頭ページを使う。新しい未使用資料の品質評価には数えない。

固定した4画像（PDFKit thumbnail、PNG往復、明示RGBA8への描画、別のCoreText RGBA8対照）を、
既定Documents、ja/en・自動言語検出OFFのDocuments、既定accurate Textへ各1回だけ渡す。
全12条件で画像形式、元画素のハッシュ、呼出し開始・完了・nativeエラー・元候補を記録する。
画像や文字の正解は認識へ渡さない。形式変換後の画素を元画像と同一と仮定しない。

一条件の認識エラー後も残る独立対照の記録を完了するが、エラーが一つでもあれば終了値1とする。
失敗を成功扱いにせず、同じ条件の押し直し、モデル切替による採用や時間切れ救済を行わない。
結果は原因の比較にだけ使い、全文書復旧・モデル品質・iPhone実機の成功へ加算しない。

SDK27の専用workflowで実行し、所有する字体・PDF・画像・依存・module cacheは終了時に削除する。
学校資料を取得せず、Actions cache・artifact・追加Releaseを作らない。
実測・失敗・次の判断は開発規約に従い失敗索引と検証記録へ分ける。
