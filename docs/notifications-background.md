# 更新確認と通知

たくポケでは、学校ファイル・学校行事・学生向けデータの更新を確認します。通知を使うには、iPhone側の通知許可とアプリ内の設定が必要です。

## 通知を設定する

**設定 → 通知**を開き、必要な種類をオンにします。

- **時間割変更**：今日以降で、選択中のクラスに関係する変更を通知します。
- **試験・返却**：選択済みの試験・試験返却PDFが更新され、解析できたときに通知します。

初めてファイルを読み込んだときは、比較の基準として保存するため通知しません。通知の種類は個別に切り替えられます。iPhone側で通知を拒否している場合は、iPhoneの設定も確認してください。

## 更新が確認されるタイミング

- 選択したPDF・XLSXは、アプリを開いたときや戻ったときなどに変更を確認します。
- 取得済み年度の学校行事は、更新の有無を確認します。
- リンク一覧・名称データ・授業時刻は、新版があればホームや設定に案内が出ます。**新版の取得には利用者の操作と認証が必要**です。

アプリを閉じている間のバックグラウンド確認もiOSに要求しますが、**毎時・即時などの実行は保証されません**。低電力モード、Appのバックグラウンド更新、通信環境、OneDriveの同期、端末のロック状態などが影響します。

通知が来なくても、必要な予定はアプリを開いて確認し、重要事項は学校の公式案内を確認してください。
