# データの保存と削除

たくポケでは、利用者が選んだ学校ファイルを**iPhone内に保存して解析**します。リンク一覧や名称データ、授業時刻は学校アカウント認証などを経て取得します。

利用規約・プライバシーポリシーの正式な内容は、アプリ内の**設定 → このアプリについて**から確認してください。このページは、利用時に知っておきたい要点です。

## 保存するもの

- 選択した時間割PDF・XLSXのコピー、解析結果、再アクセスに必要な情報
- 取得したリンク一覧、名称データ、授業時刻
- 選択クラス、リンクのお気に入り・色・非表示、通知などの設定
- 取得した学校行事

学校ファイルなどの非公開データは、iOSのファイル保護を用い、バックアップ対象から除外します。学校ファイルの通常解析や端末内AI・OCRの復旧処理では、対象資料をクラウドAIへ送信しません。

## 4月1日・10月1日の切替

**日本時間の毎年4月1日・10月1日の切替後**に、学校由来の非公開データをアプリ内から削除します。アプリをしばらく開いていなかった場合は、次に利用するときに処理されます。

**削除される主なもの**：学校ファイルのアプリ内コピー・選択情報・解析結果、取得済みリンク一覧・名称データ・授業時刻、通知の比較用データなど。

**保持される主なもの**：クラス、お気に入りなどの個人設定、取得済みの公開学校行事、OneDriveなどの元ファイル。

切替後は、**設定 → 時間割ファイル**からファイルを選び直し、**設定 → リンク・名称・授業時刻**で再取得してください。

## 認証と外部サービス

学校向けデータの認証には「たくにん」および必要に応じてMicrosoftを使用します。アプリの認証用アクセストークンは永続保存しません。外部リンクを開いた先やOneDriveには、それぞれのサービスの取扱方針が適用されます。

アプリ自体を削除すると、iPhone内のアプリの保存データも失われます。**通常のアップデートのためにアプリを削除しないでください。**
