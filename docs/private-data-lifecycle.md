# 非公開データの管理

## 取得・更新・表示

リンク一覧・名称データ・授業時刻は一回のOIDC認証で取得します。scopeは`openid mapping.read links.read`です。Tokenは永続保存しません。リンク一覧の全リンクは認証必須で、配信元が非表示にしたリンクは応答から除外します。

通常の更新確認では、各データの公開revisionを確認します。新版の取得は利用者が操作して認証した後に行います。3種類の検証・保存は独立しており、一方の失敗で他方の正常結果を取り消しません。保存済みデータは半期中、オフラインでも使用できます。

## 削除の時期と対象

日本時間の4月1日・10月1日の半期切替後、次のアプリ内データを削除します。4月1日は年度切替も兼ねます。半期管理方式への初回移行でも同じ削除を行います。

- 学校ファイルのコピー、解析結果、選択情報、ブックマーク。
- 名称データ、リンク一覧、日付別授業時刻。
- 診断情報、通知の比較基準と送信待ち情報、通知センター内のアプリの通知。

クラス・留学生表示・お気に入り・リンクの色と非表示・メインカラー・ブラウザ選択・通知などの個人設定、公開の学校行事、OneDrive上の原本は保持します。削除後はファイルの再選択と学校アカウント認証が必要です。

保存領域とデータベースの構成は[保存設計](local-database-design.md)を参照してください。

## 削除と競合対策

学校データを表示・読み込む前に期間管理ファイルを確認します。切替時は学校データの画面を外し、監視・認証・取得を停止してワーカーの終了を待ちます。保存先を閉じ、アプリ所有の対象だけを削除し、全削除成功後に期間を記録して空の保存先を開きます。

途中で失敗した場合は古い学校データの利用を止め、次回の再試行でも削除を続けます。起動・復帰・バックグラウンド確認時に期間を確認し、表示中は定期確認します。アプリが停止していた場合は次回利用前に削除します。判定には端末の日本時間を使用します。

学校ファイルと認証取得データには完全ファイル保護とバックアップ除外を設定します。端末ロック中に読めない場合は保護を維持して確認を見送ります。

## 診断と公開文書

公開版では従来の診断コピー操作を除外します。承認された返却PDFの位置情報専用操作だけは、数値・真偽値型の専用出力で利用できます。本文・画像・資料名・digest・日付文字列は含めず、直近1回のメモリ保持と端末内限定・10分のクリップボードだけを使います。処理開始と半期切替時に消去し、自動送信や永続保存はしません。本文入り診断の生成・エンコードは`DEBUG && TAKUPOKE_INTERNAL_DIAGNOSTICS`の場合だけコンパイルします。

iOSの規約・プライバシーポリシーはアプリ内に同梱し、「設定」→「サポート」→「このアプリについて」から読めます。たくにんの文書は認証サービスの`/terms`・`/privacy`で公開し、同じアプリ情報画面からシートで開きます。Astroの旧URLは移転先へ転送します。

対応表の出典とレビュー状態は[名称データ](mapping-distribution.md#保存期限と出典)に記載しています。配信サーバーに自動失効期限は設けません。

## 検証

架空データで年度・半期境界、削除対象、個人設定の保持、部分失敗からの再試行、処理との競合を検証しています。2026年10月1日には、実機で保存データと選択情報の削除を確認しました。実機での個人設定保持など、未確認の条件は[開発状況](roadmap.md#残る実機確認)に記載しています。

各版のテスト・配布・実機確認は[検証記録](verification.md)、画面の自動確認は[シミュレーター検証](simulator-verification.md)を参照してください。

## 保存期間の管理情報が破損した場合

管理マーカーの欠損、正常な期間、読取不能、JSON/期間値の破損を区別する。期間を確認できない間は学校データと認証付き取得を停止し、読取不能では初期化せず再試行を案内する。破損した管理情報だけは利用者の明示確認後に隔離できる。ワーカーと監視を停止してから破損マーカーを隔離し、学校由来の所有データを削除して現在の期間をatomicに記録する。正常な期間へ旧資料を推定移行しない。隔離・削除・マーカー書込・隔離領域の回収の失敗時は利用を再開せず、残る処理を次の再試行で完了する。個人設定・公開行事・外部原本は対象にしない。期間未確定による一時停止ではOS通知履歴を消さず、実際の期間切替/明示初期化時だけ通知をリセットする。
