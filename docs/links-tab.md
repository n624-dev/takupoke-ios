# 一覧（リンク）の使い方

**一覧**タブは、学生向けサイトのリンクを探して開く画面です。最初にリンク一覧の取得が必要です。

## リンク一覧を取得する

**設定 → リンク・名称・授業時刻**を開いて「リンク一覧」を選び、取得します。名称データや授業時刻も同時に必要なら、まとめて選択できます。

**リンク一覧だけ**の取得は、学内ネットワークならMicrosoft認証を省略できる場合があります。学外または学内と判定できない場合は学校のMicrosoftアカウントで認証します。名称データ・授業時刻にはMicrosoft認証が必要です。

## 探す・開く

- 一覧上部の検索欄に名前などを入力して探せます。
- リンクを**タップ**すると開きます。
- **設定 → リンクの開き方**で、アプリ内・デフォルトのブラウザのどちらを使うか選べます（アプリ内表示は対応するHTTPSリンク）。
- リンクを**長押し**すると、その一回だけ別の開き方を選べるほか、お気に入り・色・非表示の操作ができます。

## お気に入り・非表示

リンクを長押ししてお気に入りに登録すると、ホームからも開けます。非表示にしたリンクは、一覧右上の**「非表示のリンク」**から再表示できます。

お気に入りや表示設定は**このiPhone内**に保存されます。Web版の個人設定とは自動同期しません。

## シラバスの学科

**設定 → シラバスの学科**で該当する学科を選ぶと、対応する高専Webシラバスのリンクを学科・年度に合わせて開けます。未設定の場合は元のリンクを開きます。

リンク先のWebサイトで別途ログインが必要な場合があります。
