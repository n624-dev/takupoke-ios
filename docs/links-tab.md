# 一覧タブの仕様

`takupoke-astro` と同じ公開リンクデータを、iOS版ではSwiftUIで表示します。iOSのタブ順は「ホーム → 一覧 → 時間割 → 設定」です。Web画面は埋め込みません。

## データと更新

- `https://takupoke-api.n624.jp/links` の `v1` 応答を取得します。APIの編集・公開処理とWeb版は変更しません。
- 一覧タブを開いたときに保存済みの結果を先に表示します。前回の正常確認から5分以上経過していれば更新を確認します。引き下げ更新は時間に関係なく確認します。アプリ起動時には一覧の通信を行いません。
- 保存済みETagは `If-None-Match` で送ります。200は応答を検証してから本文・ETag・確認日時をまとめて保存し、304は本文を維持して確認日時を更新します。
- 不正応答、通信・保存の失敗時は保存済み一覧を残します。初回取得に失敗した場合はエラーと再試行操作を表示します。
- API側の `visible: false` と利用者が非表示にしたリンクは、通常一覧・お気に入り・検索結果から除外します。

## 画面と端末内設定

- カテゴリ順とリンク順はAPIの順序を使います。通常表示ではお気に入りを先頭にまとめ、検索中はWeb版と同じ正規化・かな／ローマ字展開・一致度の順で結果を並べます。
- 設定の「一覧」→「リンクの開き方」で、HTTPSリンクを「外部で開く」または「アプリ内で開く」から選べます。既定値は従来どおり外部です。外部はiOSの `openURL`、アプリ内は `SFSafariViewController` を全画面で表示します。`jrshikoku:` リンクは設定に関係なく対応アプリへ渡します。開けない場合は従来の案内を表示します。
- HTTPSリンクの行を長押しすると、設定と逆の開き方をその1回だけ選べます。設定値は変更しません。長押しではお気に入り、色変更、非表示も操作できます。お気に入りと非表示はスワイプからも操作できます。色は既定色に戻せます。
- 右上の「非表示のリンク」では、利用者が非表示にしたリンクを1件ずつ再表示できます。API側が非表示にしたリンクはここに出しません。
- お気に入り・非表示・色変更はリンクIDをキーに端末内へ保存します。APIから一時的に消えたリンクの設定も削除しません。Web版の個人設定とは同期しません。

## 確認範囲

本番 `/links` が `v1`、5カテゴリ・26リンク、ETag付きで200を返すことを開発環境から確認しました。iOSのビルド・実機での表示と操作は別途確認して[検証記録](verification.md)へ記載します。学校の実データはリポジトリやテストへ保存しません。
