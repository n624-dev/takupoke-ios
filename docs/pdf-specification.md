# PDF解析の仕様

通常時間割・試験時間割・試験返却時間割を端末内で解析・保存し、解析結果と時間割に表示します。現在の解析バージョンは通常時間割8、試験・返却6です。旧学校行事PDFの解析器はバージョン4を維持し、現在の行事表示にはAPIを使用します。

## 通常時間割の書式

令和年度・前期または後期が明記された1ページの表を対象とします。月〜金の各8時限、学年・クラスの列、セルの罫線を確認し、横に結合された授業を各時限へ展開します。科目・教員・教室はセル内の行と対応順から読み取ります。見出し・罫線・クラス・並記の対応を確認できない場合は、部分的な成功として保存しません。

PDFKitで文書を開き、通常時間割はCore Graphicsの文字描画命令と罫線から解析します。ページ回転を表示座標へそろえ、文字コードの出現順を保持します。文字の矩形はToUnicode、フォントの幅・上下寸法、文字間隔・行送り・文字行列・描画行列から計算します。

対応するフォントは1バイトのType1・TrueType、およびIdentity-HのType0（CIDFontType0・CIDFontType2）です。明示的なToUnicodeとFontDescriptorを必須とし、CIDの幅がなければ規格のDW既定値を使用します。継承CMap・縦書き・未対応文字・Form XObject・クリッピング・不可視文字は拒否します。

文字列断片は上端・下端がそれぞれ0.35pt以内で一致し、読み順と位置の対応が確認できる場合だけ同じ行として連結します。包含・同位置・逆順や曖昧な所属は拒否します。描画から得た全文をUnicode正規化し、空白以外の文字の種類と個数がPDFKitの全文と一致することも検証します。

授業ごとに分割した教室名では、半角カナ直後に同じ半角濁点・半濁点が連続した場合だけ重複を1つへ補正します。科目・教員・学校行事や元セル本文の`sourceText`は補正しません。

解析器は年度・学期を保存します。適用期間は表示側で、前期を4月1日〜9月30日、後期を10月1日〜翌年3月31日と判定します。学期不明の場合は通常授業の適用を保留します。

## 同じ時間枠に並記された授業

通常時間割には、同時刻に実施される複数の授業について、科目・教員・教室が対応する順番で並記された欄があります。確認できた並記形式では、それぞれを同じ時間枠の別の授業として保持します。

- 科目・教員・教室を、元の並び順を保って対応付ける。
- 区切りの前後に空欄があっても削除しない。教室欄の先頭が区切り記号の場合、最初の授業の教室は未記入であり、次の授業に後続の教室を対応付ける。
- 教室が未記入の授業について、隣の授業の教室や科目名から場所を補わない。
- 中黒を含む文字列をすべて機械的に分割するのではなく、科目・教員・教室の対応を確認できる書式を対象とする。対応が曖昧な場合は推測で確定しない。

## 教室の略称と正式名

授業ごとの分割・対応付けを終えた後に、各授業の教室の略称を対応表で変換します。教室欄全体を先に変換すると、区切り記号や空欄を失って別の授業に教室を割り当てるおそれがあります。

- PDFから取得した元のセル本文と、分割後の教室の略称を保持する。教室の略称には後述の重複記号補正を適用する。
- 正式名には、対応表で確認済みの所在地・階数などの括弧内表記も含める。
- 比較用の時間割CSVで所在地が省略されていても、その表記に合わせて正式名を短縮しない。
- 分割後の略称と対応表のキーに違いがある場合は、確認できた対応関係に基づいて扱う。区切り付きのキーを無条件に教室名として扱わない。
- 未確認の対応や対応表にない教室を、推測した正式名で置き換えない。

## 名称と表示

PDFの記載名を保持し、通常授業の詳細では取得済みの名称データによる正式名を優先します。カードでは短い記載名を使います。対応がなければ記載名を表示します。`TimetableLessonNames`は`subject`・`teacher`・`room`と、それぞれの`FullName`を分けて扱います。PDF由来の改行除去や半角カナの全角化は表示時に行います。

名称データの適用は再解析を必要としません。詳しくは[名称データ](mapping-distribution.md)と[時間割](timetable-tab.md)を参照してください。

## 試験時間割・試験返却時間割

PDFの年度・日付・クラス・時限・罫線・時刻表を検証します。授業枠の1行目を科目、2行目を教員、3行目を教室として読み取り、元セルの全文も保持します。返却PDFの枠内に短い横罫線があり、上下に別々の授業がある場合は別授業として保存します。

試験PDFの時刻は各試験日に適用します。返却PDFは注記に従い、初日だけ右側の専用時刻、残り4日は通常授業の時刻を使います。PDFに明記された連続時限の範囲を優先し、明記がない結合セルはその日の各時限の開始・終了から求めます。時刻の根拠を一意に確認できなければ表示しません。

試験と返却の日付が重なる場合は両方の授業枠を表示します。特別時間割がある日・クラスの空欄は通常授業で補いません。変更XLSXはこれらの授業より優先します。PDFの時刻は日付別授業時刻APIより優先し、試験資料がない試験日の変更枠へ通常時刻を流用しません。

選択した原本と最後の正常結果は分けて保存します。解析バージョン更新時は保存原本を再解析し、失敗した場合は前回正常結果を保持します。

## 旧学校行事PDFと休業期間

学校行事は、年度と12か月が確認できる2ページの表を対象とし、「共通」「詫間」をそれぞれ日付・対象欄・記載内容として保持する。「高松」の記載と、授業週数の数字・登校日記号は行事として取り込まない。1〜3月の西暦は学校年度の翌年になる。

休業の期間は、開始日の欄にある終了日表記、または罫線とは区別できる矢印の先端から確認する。月末までの矢印と翌月初日からの矢印は、対象欄・位置の対応を確認してつなぐ。終了日を含む期間として表示する。文字と矢印の終了日が食い違う場合や一意に読めない場合は、終了日未確認として元PDFの確認を促す。

本節は旧PDFの解析・保存互換性の仕様であり、現在のAPIタグとは別に扱う。時間割の行事表示にはAPIの結果を使う。欄外の注記は日付付き行事に混ぜない。比較用CSVにあっても、PDFの対象欄にない予定は取り込まない。

## 行事タグと統合時の扱い

参照CSVの分類は `NO_CLASS`（授業なし）、`WEEKDAY_OVERRIDE`（曜日振替）、`SPECIAL`（行事）の3種類です。参照CSVでは、補講日が `NO_CLASS` と `SPECIAL` の両方に含まれます。CSVの分類をタイトルだけから推測して完全再現する処理にはしません。

旧PDF解析器では、確認済みの分類を次のタグとして保持します。現在の時間割へのAPIタグの適用は[時間割の仕様](timetable-tab.md#学校行事api)に記載しています。

| タグ | PDFでの根拠 | 統合時の方針 |
| --- | --- | --- |
| 授業なし | 明記された休業日・休業期間、祝日・振替休日など | 通常授業なし。登校不要という意味にはしない |
| 曜日振替 | 明記された「○曜日授業」 | 指定された曜日の基本時間割を使う |
| 補講日 | 「補講日」の明記 | 基本時間割を使わず、時間割変更で指定された授業だけを扱う |
| 校内行事（授業なし） | 利用者が対象として指定した校内行事 | 通常授業なし。行事参加の有無とは別に扱う |
| 行事（授業の有無は未判定） | 上記のいずれにも確定できないもの | 行事名から休講を推測しない |

祝日はPDFに書かれた名称を認識します。[内閣府の祝日一覧](https://www8.cao.go.jp/chosei/shukujitsu/gaiyou.html)を名称の確認に使い、春分日などを独自計算したり本番サイトへ自動照会したりしません。PDFの記載名は変えず、タグを別に保持します。対象語への言及だけの説明文・試験・式典・補講日の相談会などを、休業や補講そのものと同一視しません。同じセルに異なる扱いの指定が併記され、一意に扱えない場合は「分類を要確認」とします。校内行事は、利用者が確認した体育祭・体育大会（季節名付きも含む）・文化祭（学校資料の総合文化祭・電波祭を含む）とその準備・準備日を対象とします。休業と対象校内行事が同じ欄に明記されている場合は、いずれも通常授業なしのため、より具体的な校内行事タグを表示します。

## 上限・失敗・保存

ファイルは50 MiBまでとし、ページ数・文字数・描画量・レコード数にも上限を設けます。暗号化・破損・画像だけのPDFは未対応です。読み取り中も中止要求を確認します。

罫線・矢印の塗りつぶし処理では各図形の境界を一度だけ計算し、点の走査・図形の走査・矢印と軸の比較・線分の処理を、ページ全体で合計1,000,000回までに制限します。描画命令の回数制限とは別に数え、内部ループでも128回ごとと描画開始時に中止要求を確認します。上限や中止で失敗した場合も前回正常結果を保持します。

未対応書式・不一致・不正な矩形などでは、確認箇所と`P01`〜`P21`の固定コードを表示します。授業欄のエラーにはクラス位置・曜日・時限・行数などの数値も付けます。失敗は試行情報として保存し、選択したファイルと前回正常結果を保持します。

## 実機での確認手順

1. 「設定」→「データ」→「時間割ファイル」で選択し、自動解析後に「詳細を見る」を開きます。必要なら「解析する」を押します。
2. 年度・学期・クラス・日付・時限、科目・教員・教室・時刻を「保存済みのPDFを見る」と照合します。同じ枠の別授業と空欄も確認します。
3. 再起動後の選択・解析結果の保持を確認します。半期切替後は再選択が必要です。
4. 架空の未対応PDFで失敗後の選択と旧正常結果の保持を確認し、元ファイルを選び直して復旧します。

公開の報告には種類・ページ・固定コード・対象位置を使用します。本文・個人名・ファイルそのものは公開Issueへ追加しません。確認済みの版と残る条件は[検証記録](verification.md)に記載しています。

## 内部診断

公開版には診断コピーの操作を表示しません。全文読み取り・エンコードは`DEBUG && TAKUPOKE_INTERNAL_DIAGNOSTICS`の場合だけ有効です。

内部診断はPDFKitの全文・文字範囲・矩形・行、ページ寸法・回転、罫線・矢印、処理経過と固定エラーを記録します。本文や個人名を含むため、学校の実資料由来の診断は非公開の調査で扱います。診断から授業データを作ったり、不明な位置を補ったりしません。

全文はメモリ内でJSONをZIP圧縮し、`TAKUPOKE-PDF-FULL-ZIP-1`とBase64としてコピーします。圧縮失敗時は`TAKUPOKE-PDF-FULL-JSON-1`を使用します。直近1回だけメモリに保持します。最大12ページ、ページ本文各100,000 UTF-16単位、文字詳細全体100,000単位、行範囲全体100,000件、数値履歴16,384件を上限とし、不完全な部分には理由を記録します。

内部版の保存済みエラー診断は`TAKUPOKE-PDF-TRACE-1`または旧形式`TAKUPOKE-PDF-GEOMETRY-1`です。コピーは利用者の操作で行い、端末内限定・10分の有効期限を設定します。
