# カウントダウン

「設定」→「カウントダウン」から、学校行事を選ぶか、名前と日付を入力して予定を登録できます。学校行事では取得済み年度を選べます。行事が未取得の場合は、その年度を取得してください。学校行事には自分用の名称を付けられます。元の行事と日付は、同じ行事IDで配信された内容に追随します。

試験の自動表示を有効にすると、「次の試験期間」または「選択クラスの次の試験日」を選べます。次の試験期間は公開行事を使い、固定登録と同じ行事を選んだ場合は固定登録の設定を使います。クラス別の試験日は選択クラスと、端末で受理された試験時間割・変更の結果を使います。自動表示の設定は半期切替後も残り、資料を再取得すると対象を再計算します。

ホームには表示条件を満たす最大3件が出ます。期間中を優先し、開始日と終了日で並べます。「すべて見る」や設定で終了済みの予定も編集・削除できます。複数の実施区間がある行事の詳細では、実施日を区間ごとに表示します。起点日を指定すると、設定期間の経過率を表示します。

通知は予定ごとに設定し、初期状態はオフです。有効にすると日本時間で予約し、既定は7日前と前日の20時です。ホームの表示条件とは独立しています。元PDFに差異がある場合や元の行事を見つけられない場合は、学校行事に結び付く通知を保留します。通知の許可と予約結果は予定の詳細で確認できます。

試験の自動表示は当日または直近の対象を1件表示します。通知を有効にすると、学校全体・選択クラスのどちらでも、確認済みの後続の試験期間・試験日まで通知を予約します。固定登録済みの学校行事はその登録の通知設定を使います。起動直後の読み込み中は、選択中クラスの予約を保持し、読み込み後に照合します。時間割変更を読み込めなかった場合や、現在の変更資料の解析が未確認の場合は、選択クラスの試験通知を保留します。

端末内の試験資料に由来する通知は、4月1日・10月1日の保存期限以後へ予約しません。期限処理では試験資料と通知を削除し、公開行事、個人予定、個人設定は保持します。

[学校行事の取得と更新確認](materials.md#学校行事api) · [通知とバックグラウンド更新](notifications-background.md)

保存した設定を読み込めないときは、カウントダウン設定の「読み込みを再試行」を使えます。破損が確認できた場合は「元のファイルを保全して初期化」を選ぶと、元のデータを端末内に残して空の一覧から再開します。「予約済み通知を取り消す」で、復旧前でもカウントダウンが予約した通知を取り消せます。元ファイルの設定とほかの機能の通知は保たれます。
