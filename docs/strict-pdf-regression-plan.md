# Strict PDF解析の互換性に関する未実装方針

未対応条件の評価には独立した架空PDFを使う。
原本・原文の値・原本の名前だけを置換した入力は使わない。

## 優先する背景判定の変更案

背景・文字・罫線の範囲、描画順、色、塗り規則を対応づける。
ページ単位の「文字を一度でも描いた」と色の最小〜最大の集約に依存しない判定へ変更する。
必要な原文IDと座標を保持し、原文のsourceOrderを描画イベント番号へ転用しない。
通常の直接文字抽出と試験／返却のPDFKit選択検証は維持する。
試験／返却を通常用字体Readerへ全面的に切り替えない。
既存経路に補助情報を足し、必要な文字との対応を証明できない場合の扱いを独立した対照で確認する。

R265の文字描画後・stroke併用・細線の条件を区別する。
見出しが先に描かれていても、その見出しと重ならず、後続する対象文字より先の背景を評価する。
実際に先行文字や罫線を覆う塗りは保持しない。
塗りとstrokeが同時の場合は、背景の内側と枠線の実際の範囲を分けて評価する。
細線が文字へ重なる場合の拒否を一律解除しない。
空の文字描画命令を可視文字の描画済みと混同しない。

R267の色差は、その文字の位置に実際に存在する背景に対して確認する。
離れたセルの背景を混ぜず、背景色の連続区間を架空の背景色として扱わない。
未被覆の白面は、対象文字がその面にある場合だけ対応させる。
塗り／輪郭／両方のモードと描画順を保持し、可視な黒い輪郭を持つ白塗り文字も比較する。
単純なfillとstrokeのAND／ORを最終表示の証明にしない。
4.5の閾値を緩める前に、位置対応と最終的に残る文字の描画を正しく検査する。
239.1になかったコントラスト閾値をStrictの必須条件にする妥当性は別に評価する。
その扱いを変える場合は、同色・消失・不透明な遮蔽を拒否する代替の対照を先に検証する。

R270では、まず相互に内部が重ならない軸平行の矩形を一括で塗る形式を評価する。
各矩形を元の順序・位置・色・f／f*の塗り規則と結びつける。
重複・入れ子・穴・逆向き相殺・未知の形状は初期の対応範囲へ含めない。
文字と構造線の消去を検査し、処理数・比較数の上限と取消を維持する。

独立した架空資料に、先行する別領域の見出し、異なるセルの背景、複数矩形の一括塗り、
白塗りと黒輪郭の文字、空の文字命令を追加し、239.1と候補版を同じ全文正解で比較する。
後塗り・同色・低コントラスト・罫線の消去・f*の重複相殺・windingの穴の拒否も比較する。
直接文字・位置・行・セル所属・授業数を検査し、既存の拒否対照の期待を番号変更だけで救済しない。
新規ケースが狙ったguardへ達しているかを確認してからApple環境の比較へ進む。
UI・AI／OCR・正式保存・Actions構成はこの修正へ混ぜない。

## その他の未実装比較

未対応の色空間、非標準ICC Rangeなど、現在拒否する条件の対応を比較する。
同色背景、上塗り、透明、任意表示、切れた文字、不明構造の拒否は維持する。
表示確認を追加する場合は、元の文字・位置・フォントの局所描画による決定論的検証を比較する。
OCR／AIの読み直しでStrictを代替せず、値や授業を推測で補完しない。

Strictの既存読取・構造解析と復旧captureのcompleteの証明条件を分ける方法を検討する。
証明不足のcaptureだけを理由に従来読取を一律失敗へ変えることも、証明不足のcaptureを
復旧のcompleteや正式採用の根拠へ昇格することも避ける。P23の全解除や全面巻き戻しは行わない。

AI設定OFF／ONの実処理で同じStrict結果になり、OFFではOCR・モデル呼出し0であることを確認する。
利用者の3文書の実機確認と、架空資料・CIの成功を区別する。

背景と文字の位置別の対応を比較する場合は、実際の文字描画順と字形の範囲を保持する。
別セルの背景を理由に文字の可視性を推定せず、上塗り・同色・透明・clipの拒否対照を維持する。
安全性を確認できない重なりは自動採用へ昇格しない。

overprintを含む背景を対応対象にする場合は、単色の色比較ではなく実合成の対照を用意する。
複数の背景・文字・罫線について最終表示と所属を検証できる条件へ限定する。
