# Strict PDF解析の互換性に関する未実装方針

塗り矩形の形状・可視性と、罫線としての採用条件を分離する。
全取得文字と実glyphの描画範囲に重ならない、形状を検証できる軸平行矩形は、
幅が罫線の支持範囲外でも文書全体を拒否せず、装飾として扱う。
細い矩形だけを従来の条件で罫線へ使い、広い塗りからセル境界を生成しない。
文字との重なり・遮蔽、非矩形、透明や未知の描画状態の拒否は維持する。
元の図形・文字位置・順序を保持し、描画順を変えた架空資料と拒否対照で検証する。
重なり自体が原因なら、この変更を復旧済みとせず、背景と上塗りの区別を次に検討する。

PDFエラー表示は要約、確認箇所、ページとP／R番号、正常結果の保持を行ごとに分ける。
描画の拒否に年度・見出しの説明を重ねず、分類に合った短い文面を使う。
番号・対象セル・保存互換を保持し、同じ表示を全文表示と読み上げで確認する。

239.1を比較基準に、通常・試験・返却の独立した架空PDFで、文書全体の授業投影を
旧Readerと現行Readerの同じ入力で比較する。文字、順序、座標、セル所属、授業数を確認する。
原本・原文の値・原本の名前だけを置換した入力は使わない。

色付き背景、未対応の色空間、非標準ICC Rangeなど、現在拒否する条件の対応を比較する。
同色背景、上塗り、透明、任意表示、切れた文字、不明構造の拒否は維持する。
表示確認を追加する場合は、元の文字・位置・フォントの局所描画による決定論的検証を比較する。
OCR／AIの読み直しでStrictを代替せず、値や授業を推測で補完しない。

Strictの既存読取・構造解析と復旧captureのcompleteの証明条件を分ける方法を検討する。
証明不足のcaptureだけを理由に従来読取を一律失敗へ変えることも、証明不足のcaptureを
復旧のcompleteや正式採用の根拠へ昇格することも避ける。P23の全解除や全面巻き戻しは行わない。

AI設定OFF／ONの実処理で同じStrict結果になり、OFFではOCR・モデル呼出し0であることを確認する。
利用者の3文書の実機確認と、架空資料・CIの成功を区別する。
