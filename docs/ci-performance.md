# CIの実行時間

アプリUIはiOS 26・27で検証し、配布ビルドと公開を同じRunnerで行います。処理の実行順とテストの準備を改善し、必要な検証を維持したまま所要時間を短縮します。

## 計測

`tools/timed_command.py`が各処理の開始・終了と経過秒数を出力します。対象はテスト用プロジェクト生成、シミュレーター起動、UI検証、保存・取得の検証用コンパイルと実行、Swiftパッケージのテスト、iPhone向けReleaseビルドです。ReleaseビルドはXcodeのBuild Timing Summaryも出力します。

ファイル選択UIとホストテスト・ビルドは`tools/parallel_build.py`で並列実行し、処理名を付けたログを実行中に出力します。中止・失敗時には起動したプロセス群を停止し、各処理の一時ファイルを片付けます。

## 実行順と公開条件

配布テストの成功後、iOS 26・27それぞれのUI検証2組と配布ビルドを同時に開始します。IPAは公開までRunner内に保持します。

`tools/release_gate.py`は、現在の実行ID・再実行回・コミットに対応する配布テストと両OSのUI検証を確認します。公開ジョブ自身の完了は待ちません。必要なジョブの失敗・中止・スキップ、異なるコミットや再実行回、重複ジョブ、APIエラーを検出した場合は停止します。未完了・未登録のジョブは60秒間隔で最大40分待ち、時間切れなら停止します。mainのコミットと公開物の照合は公開処理でも行います。

UIテストは最初から各テストに必要な条件で起動します。文字サイズ・空データ・更新・取得失敗の確認で、標準条件のアプリを起動してから直ちに起動し直す処理を省きます。設定の保存や通知の差分確認に必要な再起動はテストに含めます。

## UI検証の分割

`tools/ui_test_manifest.py`で18項目をA・Bの各9項目に分け、各OSの別Runnerで実行します。測定した各項目の時間を基に配分し、文字サイズのOS設定3パターンはB組で追加実行します。iOS 26のVoiceOver操作だけは従来どおり対象外で、iOS 27では実行します。

ソースに宣言されたテストと分割表を照合し、追加漏れ・古い項目・重複を検出した場合は停止します。XCTestの完了ログも選択した項目と照合し、未実行・重複・失敗・想定外のスキップを検出した場合は失敗とします。公開には両OSのA・B、計4ジョブの成功を必要とします。分割指定なしのローカル実行では全項目を実行します。

UI用4台と配布用1台を並行使用します。各Runner内のシミュレーターは1台に限定し、複数シミュレーターによるCPU・メモリの競合を避けます。分割によってUI用アプリのコンパイルと依存関係の取得は増えます。所要時間と使用時間を実測して効果を確認します。

## 計測記録

| 実行 | 全体 | iOS 26 UI | iOS 27 UI | 配布ジョブ | macOSジョブ合計 |
| --- | ---: | ---: | ---: | ---: | ---: |
| [改善前：227](https://github.com/n624-dev/takupoke-ios/actions/runs/36851802199) | 51分33秒 | 29分19秒 | 26分17秒 | 21分51秒 | 77分27秒 |
| [前倒し・起動準備の改善：228](https://github.com/n624-dev/takupoke-ios/actions/runs/36861849428) | 35分06秒 | 34分04秒 | 29分37秒 | 34分50秒 | 98分31秒 |
| [UIを2分割：229](https://github.com/n624-dev/takupoke-ios/actions/runs/36866156685) | 25分03秒 | A：19分07秒 / B：19分36秒 | A：22分51秒 / B：18分54秒 | 24分08秒 | 104分36秒 |

改善前は両OSのUI検証完了後に配布ビルドを開始していました。228の配布ジョブには公開前の待機約19分20秒を含み、IPA生成までの工程は約15分10秒でした。保存・取得の検証用コンパイルは約4分41秒、Swiftパッケージの依存関係取得・ビルド・テストは約7分48秒、iPhone向けReleaseビルドは約2分35秒でした。

229はIPA生成まで16分32秒、公開前の検証待ち7分13秒でした。全4組のUI検証の成功後に公開処理を開始し、約12秒で公開しました。Swift204件、Python54件、ファイル選択UI3件が成功し、両OSで既存のUI項目と文字サイズのOS設定3パターンを確認しています。

今回の全体時間は改善前から26分30秒、約51%短縮しました。分割に伴うビルドの重複と公開前の待機により、macOSジョブの合計は77分27秒から104分36秒へ増えました。

全体はワークフロー作成から完了まで、各ジョブは開始から完了までを測っています。macOSジョブ合計には公開前の待機も含めます。実行環境・依存関係の取得・シミュレーター初回起動による変動があるため、1回の結果だけで一定の短縮時間を保証しません。
