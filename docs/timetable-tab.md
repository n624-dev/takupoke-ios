# 時間割の見方

**時間割**タブでは、クラス・週を選んで通常授業や時間割変更、試験・返却の予定を確認できます。

## 週とクラスを選ぶ

- **「クラス」**から表示するクラスを選びます。設定画面からも変更できます。
- **「前週」「翌週」**で移動し、週の日付を押すとカレンダーから日付を指定できます。
- 授業カードを押すと、科目・教員・教室・時刻などの詳細が開きます。
- 連続した授業は、条件に応じてひとつのカードにまとめて表示されます。

## 時間割変更を見る

**「通常」「変更込み」**で週の表示を切り替えられます。休講・補講・変更などは、変更込みの表示と授業の詳細で確認してください。ホームの「今日の予定」は常に変更込みです。

週の時間割の下にある**変更一覧**は、**「今日以降」「この週」「全件」**で絞り込めます。

## 試験・返却・学校行事

試験時間割・試験返却時間割PDFは、**設定 → 時間割ファイル**から追加します。学校行事は**設定 → 学校行事**で年度を指定して取得します。必要なデータが未取得の場合、表示できない予定があります。

学校行事により授業なしや曜日振替などが表示される場合があります。**判断できない内容をアプリ側で推測して確定扱いにはしません。** 学校の案内と違うと感じた場合は、必ず元資料を確認してください。

## 表示がおかしいとき

まず**設定 → 時間割ファイル → 詳細を見る**で解析状況を確認してください。変更が反映されない場合は、OneDriveの同期や選んだファイルも確認します。文字はiPhoneの文字サイズ設定に応じて拡大できます。
