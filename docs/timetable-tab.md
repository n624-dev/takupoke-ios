# 時間割タブの表示仕様

端末内 SQLite に保存された直近の正常な `PDFAnalysis` と `ChangeAnalysis` を読み取り、画面上で週の表示を組み立てます。資料の再取得や再解析は自動実行しません。解析版と現在の原本のハッシュが異なる場合は警告を表示します。採用版を保存する処理はまだありません。

## 日付と授業

- 学校の日付と週の開始日は日本時間で決め、週は月曜から日曜までです。前週・翌週は7日単位で移動します。
- 通常時間割の前期は `schoolYear` の4月1日から9月30日まで、後期は10月1日から翌年3月31日まで適用します。終了日の翌日を排他的な境界として扱います。
- `term` が不明な PDF からは通常授業を表示せず、再解析を案内します。適用期間外にも通常授業を流用しません。
- 「通常」は PDF の授業だけを表示します。「変更込み」は、変更行の日付・クラス・時限がグリッドに一致すると、その枠の通常授業を変更後の表示で置き換えます。変更前の科目名の一致は要求しません。元の通常授業は変更詳細に残します。同じ枠に複数の変更行がある場合は全件を表示し、優先順位を推定しません。
- 変更後の科目が空欄でも変更行を表示し、内容の確認へ進めます。時限が1〜8の単独番号として読めない行は週グリッドに割り当てず、変更一覧で閲覧できます。
- 変更一覧は保存済み XLSX の全行を元に「今日以降」「この週」「全件」を切り替えます。週グリッドのクラス設定は基本1クラスです。2クラスの場合は、保存済み解析に存在する1年生のホームルーム（番号1〜3）から1つ、2文字の学科識別子から1つだけ組み合わせられます。変更一覧の対象クラスは別のグループ別選択で最大30クラスまで指定でき、時間割の選択へ戻せます。

## Astro 版との照合

参照元はローカルの `takupoke-astro` のコミット `edfaf85` です。確認した主機能の対応状況は次の通りです。

| Astro の機能 | iOS の状態 |
| --- | --- |
| 基本1クラス、1年生だけホームルーム＋学科を選択。変更一覧用の別選択 | 選択構造は対応。iOS のクラスIDはアンダースコア区切りで、追加候補は保存済み解析に存在するクラスから判定する。Astro の固定候補集合との完全一致は未確認 |
| 前週・翌週、通常／変更込み | 対応 |
| 週グリッド、授業タップで詳細と通常授業の表示 | 対応。iOS は月曜〜日曜を表示 |
| 変更一覧の今日以降／この週／全件 | 対応 |
| 再読み込み | 保存済みの解析結果が更新されると自動再表示。資料更新・再解析は「学校資料」から手動で実行 |
| 週画像の共有・保存 | 未実装 |
| 学校行事による授業なし・曜日振替、試験の特別時間、週の行事表示 | 未実装。既存の行事解析・タグ付け規則は変更していない |
| 授業開始・終了時刻、試験期間名 | 現在の iOS 解析結果に値がないため未表示 |

この表の「対応」はコード上の実装を指します。iOS SDK ビルドと実機表示の確認状況は[検証記録](verification.md)に記します。
