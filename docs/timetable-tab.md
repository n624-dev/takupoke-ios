# 時間割タブの表示仕様

端末内 SQLite に保存された直近の正常な通常時間割 `PDFAnalysis` と `ChangeAnalysis`、試験時間割PDF・試験返却時間割PDFの解析結果、および年度ごとに保存した学校行事APIの結果を読み取り、画面上で週の表示を組み立てます。旧行事PDFの解析結果は週表示に使用しません。時間割タブを開くだけでは行事データを再取得しません。設定画面でPDF・XLSXを取得すると自動解析します。採用版を保存する処理はまだありません。

## 日付と授業

- 学校の日付と週の開始日は日本時間で決め、週は月曜から日曜までです。土曜・日曜に開くと次の月曜の週から始めます。前週・翌週は7日単位で移動し、表示週の中央の日付を押すとカレンダーから週を選べます。前週は、開いた学期と候補の週が1日でも重なる場合に表示します。10月の学期から開いた場合、9/28〜10/4までは戻れますが、9/21〜9/27へは進めません。次の学期へは保存済みデータがある週に続けて進めます。一度進んだ週からも前週へ戻れます。カレンダーは前週・翌週ボタンで到達できる週だけを選択でき、カレンダーで週を選んでも開いた学期の基準は変わりません。
- 通常時間割の前期は `schoolYear` の4月1日から9月30日まで、後期は10月1日から翌年3月31日まで適用します。終了日の翌日を排他的な境界として扱います。
- `term` が不明な PDF からは通常授業を表示せず、再解析を案内します。適用期間外にも通常授業を流用しません。
- 「通常」は通常PDFと試験・返却PDFの授業を表示します。「変更込み」は、変更行の日付・クラス・時限がグリッドに一致すると、その枠の授業を変更後の表示で置き換えます。変更前の科目名の一致は要求しません。元の通常・試験・返却授業は変更詳細に残します。同じ枠に複数の変更行がある場合は全件を表示し、優先順位を推定しません。
- 変更後の科目が空欄でも変更行を表示し、内容の確認へ進めます。時限が1〜8の単独番号、連続したカンマ区切り、または資料で確認した `1～2` 型の範囲として読める行は、対象時限をまたぐ1つのカードとして週グリッドに表示します。元の時限文字列を保存・一覧表示し、非連続・不明な表記は週グリッドへ推測で反映せず変更一覧に残します。
- 変更一覧の変更前が空欄でも、同じ日・クラス・時限に通常時間割の授業があれば科目名を表示だけ補います。XLSX原文は変えません。変更前・変更後に続く括弧は、保存済み名称対応表の教員・教室の略称に完全一致するものだけを分けて表示します。科目の一部や未一致の括弧は科目名に残し、詳細・解析結果から原文を確認できます。
- 通常PDFと試験・返却PDFは、同じクラス・日の隣接時限で科目・教員・教室がすべて一致する授業を1つのカードにまとめます。表示時だけの結合であり、保存済みの各時限の解析結果は書き換えません。重なる別の授業・変更は横の別レーンに表示します。
- 週グリッドの授業カードは各時限の左上を基準に配置し、カードを描画する範囲を割り当てた時限内に収めます。日付見出しの高さは、行事名と未解析警告を含め、週内で必要な最大の高さにそろえます。選択中のクラス名はグリッド内に繰り返し表示せず、上部の選択欄と授業詳細で確認できます。空欄の「—」も枠の中央に表示します。
- 時限欄・日付見出し・授業カードの文字を上下左右中央に配置します。時限番号は左欄の「1」「2」などにだけ表示し、カードには繰り返しません。共通時刻とカード固有の時刻は開始時刻・「～」・終了時刻を3行に分けます。カードには「試験時間割」などの資料種別を表示せず、詳細で確認できます。1クラスで授業が横に重ならない平日5日分は無印iPhoneの横幅に収まるよう、時限欄44pt・日欄58pt・各時限100ptを使います。グリッド内側の左右余白を置かず、収まらない文字は「⋯」で省略します。教室名だけは全角表記が収まらなければ半角カタカナを試してから省略します。
- 授業カードの文字は上下左右の中央に配置します。「授業なし」等で通常授業が抑制された日に、選択中の全クラスで変更・試験・返却を含む授業が1枠も表示されない場合、その日の1〜8限を1つの行事カードにまとめ、行事の件名を中央に表示します。授業が残る日は行事カードを作らず、その授業枠を表示します。表示中の全日がこの行事カードだけなら、左の時限・時刻欄を隠し、各行事カードを1行以上の必要な高さに縮めます。
- 変更一覧は保存済み XLSX の全行を元に「今日以降」「この週」「全件」を切り替えます。週グリッドのクラス設定は未設定、または基本1クラスです。2クラスの場合は固定候補の1年生ホームルーム（1〜3）から1つ、学科（CN・ES・IT）から1つだけ組み合わせます。候補は1年生ホームルーム（1〜3）、1〜5年のCN・ES・IT、AI-1・AI-2の20種類で、現在の解析結果に授業がなくても選べます。変更一覧の対象クラスは別のグループ別選択で最大30クラスまで下書き選択・適用でき、時間割の選択へ戻せます。内部IDの `_` は画面表示だけ `-` に置き換えます。
- クラス・変更一覧の対象クラス・留学生表示・通常／変更込み・変更一覧の表示範囲を端末内に保存します。通常PDFと変更XLSXの解析結果フィルターも保存します。資料の読み込み中や候補から一時的に消えたときも選択値は削除せず、現在の資料にないクラスはその状態を表示します。週の移動位置は画面表示時の現在週を基準にします。
- 「留学生向けの授業も表示」がオフのとき、科目名が「留」で始まる通常・変更・試験・返却の授業は表示しません。空白なしの「留架空科目A」のような表記も対象です。保存済み名称対応表で留学生向けと指定された科目は、「留 」を除いた科目名にも対象クラス内で一致させます。オンにすると表示します。
- 時間割タブでは、通常・変更・試験・返却の科目、教員、教室、備考、行事などに含まれる半角カタカナを表示時だけ全角へ変換します。通常授業のグリッドではPDFの略称、詳細では対応表の正式名を優先する使い分けは維持します。PDFやXLSXから保存した値と名称対応表の完全一致判定には、変換前の文字列を使います。Astro版の現行表示には共通の全角変換はなく、これはiOS画面で読みやすくする追加仕様です。
- 日付見出しの下には学校行事APIの件名を表示し、タグや資料種別のラベルは出しません。「行事メモ」の件名だけは日付見出しから外し、下の週の行事欄には残します。試験・返却PDFがない日の未公開・未解析警告は件名の下に残します。週の行事欄は日ごとに件名を `・` でつないで1つの欄へ表示し、長いときは折り返して全文を表示します。件名の後ろにAPIタグは表示しません。授業へのタグ適用規則は維持します。

## 学校行事API

- APIから年度別に初回は手動取得し、版・日付・タグを検証して端末内へ保存します。起動時は保存済み年度をレスポンスETagで条件付きGETし、304なら本文を取得せず、200なら検証後に更新します。失敗時は保存済み結果を維持します。公開されていない年度や取得失敗時に旧行事PDFへ戻しません。既存のPDF解析・タグ付け規則は変更しません。
- API確認後、起動時に元PDFをダウンロードせず、学校サイトのHEADで別の `sourcePdfETag` を確認します。差異や通信失敗を警告し、保存済み行事は表示し続けます。元PDFのETagの一致は本文SHA-256の厳密な検証ではありません。
- APIの「授業なし」「行事（授業なし）」は通常授業を表示しません。変更XLSXと試験・返却PDFの授業は残します。「補講日」は従来どおり通常授業を補わず、変更で指定された授業を表示します。「曜日振替」は明示された曜日の通常時間割を使います。
- 「テスト」「テスト返却」の日は通常授業を補いません。対応する試験・返却PDFが未公開・未解析のクラスにはその旨を表示します。2種類が重なる日には両資料の授業枠を合わせて表示します。
- 「行事（時間割変更）」「行事（授業あり）」「行事」「行事メモ」は行事として表示します。授業枠はXLSXや試験・返却PDFに変更があるときだけ変わります。「行事（時間割変更）」による時刻変更は後の対応に分けます。

## 試験時間割・試験返却時間割

- 試験PDFと試験返却PDFは、「設定」→「ファイル選択」から iOS「ファイル」で個別に選びます。OneDrive のファイルは File Provider 経由で端末内にコピーします。選択した原本と最後に成功した解析結果を別の端末内 SQLite 領域で管理し、解析に失敗しても選択状態と前回の正常結果を保持します。各資料の「詳細を見る」から結果と全文診断を確認し、右上の「解析する」で再解析できます。
- 添付資料で確認できた試験PDFの6ページと返却PDFの1ページの表構造を対象にします。試験最終ページの「1年」「2年」は `AI_1`・`AI_2` に対応させます。年度、日付、クラス、時限、表内の授業記載、PDF記載の時刻を検証します。書式が合わない資料は推測して反映しません。旧版の実機診断は文字位置の段階で停止していました。通常時間割用の描画命令リーダーが拒否するタグ・クリッピング命令を提供資料で確認したため、試験・返却はPDFKitの文字選択を1文字ずつ検証する経路に変更しました。修正版の実機確認は未実施です。
- 授業枠の1行目を科目、2行目を教員、3行目を教室として、解析結果画面と週グリッドの詳細にラベル付きで表示します。元のセルの全文も詳細から確認できます。この行の対応は利用者に確認済みです。返却PDFで1時限の枠内に短い横罫線があり上下に別々の授業を記した場合は、上下を別授業として解析します。解析器の版を上げた際は、保存済み原本を起動時に再解析し、失敗した場合は前回の正常結果を保持します。
- 試験と返却は日付が重なっても授業枠ごとに統合します。同じ枠に両資料の記載があれば両方を表示します。特別時間割がある日・クラスでは空欄に通常授業を補いません。変更XLSXは特別時間割の授業枠より優先します。
- 時限の時刻が週内で一致すれば左端へまとめ、異なれば授業セルへ表示します。試験・返却時刻と連続時限の時刻はPDFの時刻表と結合セルから取得し、対応を確認できない枠に通常授業の固定時刻を転用しません。

## Astro 版との照合

参照元はローカルの `takupoke-astro` のコミット `edfaf85` です。確認した主機能の対応状況は次の通りです。

| Astro の機能 | iOS の状態 |
| --- | --- |
| 基本1クラス、1年生だけホームルーム＋学科を選択。変更一覧用の別選択 | 対応。iOS のクラスIDはアンダースコア区切り。未設定、固定の追加候補、変更一覧の下書き選択・適用を実装 |
| 前週・翌週、通常／変更込み | 対応。東京時間の週初期値と学期境界を使用 |
| 週グリッド、授業タップで詳細と変更前授業の表示 | 対応。平日は常時、土日は授業がある場合に列を表示。同じ枠の複数授業は横の別レーンに表示 |
| 変更一覧の今日以降／この週／全件 | 対応 |
| 再読み込み | 保存済み解析の更新で自動再表示。資料の取得は「設定」→「ファイル選択」から手動で実行し、取得後に自動解析する。結果画面から保存済み資料を再解析できる。Web版の個別API再読込や通信再試行は端末内方式には該当しない |
| 週画像の共有・保存 | 未実装 |
| 学校行事による授業なし・曜日振替、週の行事表示 | 保存済みの既存分類を表示へ投影。分類が要確認の行事は授業抑制や曜日振替には使用しない。既存の解析・タグ付け規則は変更していない |
| 試験・返却時間割、時刻、種別 | 添付PDFの書式とPDF記載時刻で実装。資料未選択・書式変更時は表示できず、前回の正常結果を保持 |
| 授業詳細の正式名称 | 通常授業は保存済みの名称対応表による正式名称を優先。未一致ならPDF記載名を表示。試験・返却はPDF記載名を表示し、外部の名称対応表による補完はしない |
| 休業日の縦結合セル、試験期間名 | 授業がない休業日は8限分を1枚の行事カードにまとめる。日付下には学校行事APIの件名を表示する |

この表の「対応」はコード上の実装を指します。iOS SDK ビルドと実機表示の確認状況は[検証記録](verification.md)に記します。
