# 時間割タブの表示仕様

端末内 SQLite に保存された直近の正常な `PDFAnalysis` と `ChangeAnalysis`、試験・返却PDFの解析結果を読み取り、画面上で週の表示を組み立てます。時間割タブを開くだけでは資料を再取得しません。設定画面で取得・再取得すると自動解析します。解析版と現在の原本のハッシュが異なる場合は警告を表示します。採用版を保存する処理はまだありません。

## 日付と授業

- 学校の日付と週の開始日は日本時間で決め、週は月曜から日曜までです。土曜・日曜に開くと次の月曜の週から始めます。前週・翌週は7日単位で移動し、前の学期へは戻りません。次の学期へはその週の保存済みデータがある場合に進めます。
- 通常時間割の前期は `schoolYear` の4月1日から9月30日まで、後期は10月1日から翌年3月31日まで適用します。終了日の翌日を排他的な境界として扱います。
- `term` が不明な PDF からは通常授業を表示せず、再解析を案内します。適用期間外にも通常授業を流用しません。
- 「通常」は通常PDFと試験・返却PDFの授業を表示します。「変更込み」は、変更行の日付・クラス・時限がグリッドに一致すると、その枠の授業を変更後の表示で置き換えます。変更前の科目名の一致は要求しません。元の通常・試験・返却授業は変更詳細に残します。同じ枠に複数の変更行がある場合は全件を表示し、優先順位を推定しません。
- 変更後の科目が空欄でも変更行を表示し、内容の確認へ進めます。時限が1〜8の単独番号として読めない行は週グリッドに割り当てず、変更一覧で閲覧できます。
- 変更一覧は保存済み XLSX の全行を元に「今日以降」「この週」「全件」を切り替えます。週グリッドのクラス設定は未設定、または基本1クラスです。2クラスの場合は固定候補の1年生ホームルーム（1〜3）から1つ、学科（CN・ES・IT）から1つだけ組み合わせます。候補のうち保存済み解析に存在するクラスだけを表示します。変更一覧の対象クラスは別のグループ別選択で最大30クラスまで下書き選択・適用でき、時間割の選択へ戻せます。

## 試験・返却資料

- 試験PDFと試験返却PDFは、「設定」→「ファイル選択」から iOS「ファイル」で個別に選びます。OneDrive のファイルは File Provider 経由で端末内にコピーします。選択した原本と最後に成功した解析結果を別の端末内 SQLite 領域で管理し、解析に失敗しても選択状態と前回の正常結果を保持します。各資料の「PDFを解析・結果を確認」から再解析し、全文診断をコピーできます。
- 添付資料で確認できた試験PDFの6ページと返却PDFの1ページの表構造を対象にします。試験最終ページの「1年」「2年」は `AI_1`・`AI_2` に対応させます。年度、日付、クラス、時限、表内の授業記載、PDF記載の時刻を検証します。書式が合わない資料は推測して反映しません。旧版の実機診断は文字位置の段階で停止していました。通常時間割用の描画命令リーダーが拒否するタグ・クリッピング命令を提供資料で確認したため、試験・返却はPDFKitの文字選択を1文字ずつ検証する経路に変更しました。修正版の実機確認は未実施です。
- 試験と返却は日付が重なっても授業枠ごとに統合します。同じ枠に両資料の記載があれば両方を表示します。特別時間割がある日・クラスでは空欄に通常授業を補いません。変更XLSXは特別時間割の授業枠より優先します。
- 時限の時刻が週内で一致すれば左端へまとめ、異なれば授業セルへ表示します。試験・返却時刻と連続時限の時刻はPDFの時刻表と結合セルから取得し、対応を確認できない枠に通常授業の固定時刻を転用しません。

## Astro 版との照合

参照元はローカルの `takupoke-astro` のコミット `edfaf85` です。確認した主機能の対応状況は次の通りです。

| Astro の機能 | iOS の状態 |
| --- | --- |
| 基本1クラス、1年生だけホームルーム＋学科を選択。変更一覧用の別選択 | 対応。iOS のクラスIDはアンダースコア区切り。未設定、固定の追加候補、変更一覧の下書き選択・適用を実装 |
| 前週・翌週、通常／変更込み | 対応。東京時間の週初期値と学期境界を使用 |
| 週グリッド、授業タップで詳細と変更前授業の表示 | 対応。平日は常時、土日は授業がある場合に列を表示。同じ枠の複数授業は縦に表示 |
| 変更一覧の今日以降／この週／全件 | 対応 |
| 再読み込み | 保存済み解析の更新で自動再表示。資料の取得は「設定」→「ファイル選択」から手動で実行し、取得後に自動解析する。結果画面から保存済み資料を再解析できる。Web版の個別API再読込や通信再試行は端末内方式には該当しない |
| 週画像の共有・保存 | 未実装 |
| 学校行事による授業なし・曜日振替、週の行事表示 | 保存済みの既存分類を表示へ投影。分類が要確認の行事は授業抑制や曜日振替には使用しない。既存の解析・タグ付け規則は変更していない |
| 試験・返却時間割、時刻、種別 | 添付PDFの書式とPDF記載時刻で実装。資料未選択・書式変更時は表示できず、前回の正常結果を保持 |
| 授業詳細の正式名称 | 通常授業は保存済みの正式名称を優先。試験・返却はPDF記載の名称を表示し、外部の名称対応表による補完はしない |
| 休業日の縦結合セル、試験期間名 | 休業日は最初の時限にラベルを表示する構成。試験期間は出典種別を表示し、Web上流の期間タイトルと同じ値は資料にないため表示しない |

この表の「対応」はコード上の実装を指します。iOS SDK ビルドと実機表示の確認状況は[検証記録](verification.md)に記します。
