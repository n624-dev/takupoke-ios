# ホームの見方

ホームには**今日の予定・お気に入り・おすすめリンク**が表示されます。

## 今日の予定

選択しているクラスの当日の授業と学校行事を確認できます。授業を押すと、科目・教員・教室・時刻などの詳細を表示します。**「時間割を見る」**から、その日を含む週へ移動できます。

今日の予定は時間割変更を反映した表示です。授業が終了しても、その日の予定からは消えません。選択クラスやファイルが未設定の場合は、画面の案内に沿って設定してください。

## お気に入りとおすすめ

一覧タブでお気に入りにしたリンクをホームから開けます。表示内容は一覧の取得状況や個人設定によって変わります。

## データの更新案内

リンク一覧・名称データ・授業時刻に更新が見つかったときは案内が表示されます。案内を開いて更新対象を選び、必要に応じて学校アカウント認証を済ませて取得してください。

更新の確認や保存済みデータは、**設定 → リンク・名称・授業時刻**でも扱えます。取得に失敗しても前回の正常な結果は保持されます。
