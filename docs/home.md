# ホーム

「今日の予定」「お気に入り」「おすすめ」の順に表示します。

## 更新の案内

取得済みの一覧・名称データに新版が見つかった場合、「今日の予定」の上に更新対象を表示します。案内を押すと設定と共通の「リンク・名称・授業時刻」画面へ進み、更新操作から一回の認証で取得できます。正常に保存した対象の案内を消し、キャンセルや取得失敗時には残します。未取得のデータは更新案内の対象にしません。

## 今日の予定

- 日本時間の今日の日付・曜日と、学校行事の件名を表示します。行事メモも含め、複数の件名は「・」でつなぎます。共通の行事は一度だけ表示します。
- 時間割タブで選んだクラスを使い、複数の場合はクラスごとに表示します。クラス未選択時は選択画面へ進めます。
- 常に変更を反映した一日分を表示します。終了した授業も残ります。
- 授業の左側に開始時刻・「～」・終了時刻、右側に科目・教員・教室を表示します。連続授業は時間割と同じ条件でまとめます。
- 時間割変更は「休講」「補講」「変更」を区別します。同じ枠の休講と補講は既存の時間割と同じ優先順位で表示し、ほかの変更は詳細で確認できます。
- 授業中の行にはメインカラーの細い線と「授業中」を表示します。開始時刻を含み、終了時刻を含みません。休講や時刻不明の授業には付けません。
- 授業を押すと、時間割と共通の詳細を開きます。変更前の通常授業・試験・返却、同じ枠のほかの変更も確認できます。
- 「時間割を見る」は今日を含む週へ移動します。土日も、その日を含む週を開きます。時間割タブの通常／変更込みの設定は保持します。

通常・変更・試験・返却の授業、曜日振替、授業なし、留学生向け授業の表示は[時間割の規則](timetable-tab.md)を共用します。時刻は既存の検証済み解析結果に従い、試験・返却が必要な日に資料がなければ通常時刻で補完しません。

## 状態の表示

保存結果の読み込み中は「読み込み中⋯」を表示します。読み込みに失敗した場合は、エラーと「再試行」を表示します。必要なデータがない場合は、未取得・未解析・適用期間外などの状態を表示します。入力がそろっている日に表示対象の授業がなければ「授業はありません。」と表示します。

保存データの変更で表示を更新します。日本時間の日付と授業中の表示は、画面表示時・アプリ復帰時と表示中の15秒ごとの確認で更新します。

## お気に入り・おすすめ

一覧と共通の保存データ・色・非表示設定・リンクの開き方を使用します。詳細は[一覧タブの仕様](links-tab.md)を参照してください。
