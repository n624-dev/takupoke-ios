- 取得対象L/M/Tの全8組合せを認証開始前に確定。なしは通信・認証なし、Lのみはstandardを許可、M/Tを含めば既存Microsoft/strict一回。期限と権限を満たすtokenだけメモリで再利用し、永続保存しない。取消・期間切替では破棄。
- 一覧専用standardは本人確認・名称/時刻の権限にならない。学内確認はサーバー側で最終同意時にも行い、学外・判定不能はMicrosoft。発行済みtokenは最大10分有効で、学外移動による即時失効はしない。
- XLSXの確認は元ファイルの再取得・全体の再解析後に保存する。SHA・選択識別・年度・Parser・確認行の不一致を実中止と区別し、失敗時も画面と選択を保持。成功時だけ閉じる。以前の除外を表示し、明示的に残す行の曜日補正と組み合わせられる。
- UUIDのない旧選択は再取得前に安定識別を保存する。同じ選択・同内容の名前変更だけを維持し、新しい選択や異なる内容への確認流用は拒否する。
- 現在結果の状態はSHA・年度・Parser・曜日と除外の確認を照合。過去の別原本/年度の失敗は現在の失敗にせず、現在正常結果を保持した再解析失敗は区別して表示する。
