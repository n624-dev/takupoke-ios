# 困ったとき

[READMEに戻る](../README.md)

アプリの「設定 → サポート → 使い方」からも、初期設定・時間割・リンク・更新や通知の案内を確認できます。

## 時間割が出ない・予定が違う

1. 「設定 → クラス」で表示するクラスを確認します。
2. 「設定 → 時間割ファイル」の「詳細を見る」で、対象のファイルと解析結果を確認します。必要なら右上の「解析する」を選びます。
3. 試験・返却期間はそれぞれのPDFを、学校行事が出ないときは「設定 → 学校行事」で対象年度を確認します。

重要な予定は学校の公式案内と元の配布ファイルも確認してください。[学校ファイルと行事の取得](materials.md)

## OneDriveの変更が反映されない

OneDriveアプリで対象ファイルを開き、同期とダウンロードが完了しているか確認します。必要に応じて「オフラインで使用可能にする」を選び、iOSの「ファイル」アプリでも最新版が開けることを確認してから、たくポケで選び直します。[OneDriveの準備](materials.md#onedriveの準備)

## PDFの解析に失敗する

対象ファイルの「詳細を見る」でエラーを確認します。端末内復旧が利用できる場合は「設定 → AI・OCRを使用する」をオンにして復旧を試し、採用前に元PDFと照合します。[端末内でのPDF復旧](pdf-recovery.md)

## 通知が届かない

- 時間割変更・試験PDFの更新は、アプリの「設定 → 通知」とiPhoneの通知許可を確認します。バックグラウンドで更新を確認する時刻はiOSが決めます。
- カウントダウンは予定の通知設定をオンにし、予定の詳細で予約結果を確認します。学校行事に結び付く予定では、元資料の状態によって予約が保留されることがあります。[カウントダウンの使い方](countdown.md)

## 保存したファイルや一覧が見つからない

4月1日と10月1日の切り替わり後は、学校ファイルの再選択とデータの再取得が必要です。[データの保存期限](private-data-lifecycle.md)

## AltStoreで更新できない

AltStore ClassicのSourceや更新一覧を再読み込みします。無料のApple Accountで期限が切れたときは署名を更新します。[配布と署名更新](distribution.md) · [AltStore PAL経由の導入](altstore-pal-install.md)

## 解決しないとき

[GitHub Issues](https://github.com/n624-dev/takupoke-ios/issues)には、再現手順、実際に表示された内容、期待した動作、iOSとアプリの版を記載してください。アプリの版は「設定 → サポート → このアプリについて」で確認できます。公開Issueに添付する画像やログからは、学校の実資料、共有URL、氏名、メールアドレス、認証情報を取り除いてください。
