# 困ったとき

まずアプリの**設定 → 使い方**、および各設定画面の**「詳細を見る」**にある状態・エラーを確認してください。

## 時間割が出ない・予定が違う

1. **設定 → クラス**で表示するクラスが選ばれているか確認します。
2. **設定 → 時間割ファイル**で通常時間割PDF・時間割変更XLSXなどの選択状況を確認します。
3. 対象の**「詳細を見る」**で解析エラーを確認し、必要に応じて**「解析する」**を押します。
4. 試験・返却の期間なら、それぞれのPDFが選択されているか、学校行事が取得されているかを確認します。

元の資料と食い違うときは、**学校の公式情報を正**として確認してください。

## OneDriveの変更が反映されない

1. OneDriveアプリを開き、ファイルの同期状況を確認します。
2. 対象ファイルを「オフラインで使用可能にする」に設定して、ダウンロードを確認します。
3. iPhoneの**ファイル**アプリでそのファイルを開きます。
4. たくポケの**設定 → 時間割ファイル**から選び直します。

iPhoneの低電力モードやバックグラウンド更新の設定でも同期が遅れることがあります。アプリが自動確認しても、OneDriveに最新版が届いていなければ反映できません。

## PDFを読み取れない・復旧が必要なとき

通常時間割・試験・試験返却PDFの解析に失敗したときは、**設定 → 時間割ファイル**の「詳細を見る」でエラーと再解析の結果を確認してください。対応するPDFで復旧の案内が表示される場合は、**設定 → AI・OCRを使用する**をオンにして、端末内の復旧画面を開けます。

復旧画面では「端末内で復旧を開始」を選び、読み取った内容を**必ず元のPDFと照合**してください。正しいと確認できた場合だけ「この資料全体の結果を使用」を選びます。復旧には端末・OS・利用可能なモデルによる制限があります。復旧できない場合や結果が不明確な場合は、学校の元資料を利用してください。PDFや読み取った文字はクラウドAIへ送信しません。

## 時間割変更の日付がおかしい

**設定 → 時間割ファイル → 時間割変更 → 詳細を見る**で、年のない日付を解釈するための補完年度を確認します。必要に応じて修正し、再解析してください。

## リンク一覧が表示されない・更新できない

**設定 → リンク・名称・授業時刻**から対象を選び、再取得します。学外で一覧だけを取得する場合も、学校のMicrosoftアカウント認証が必要になることがあります。通信や認証をキャンセルした場合は、再度操作してください。

## 通知が来ない

**設定 → 通知**で対象がオンになっているか、iPhoneの設定で通知が許可されているかを確認します。初回の取り込みは通知対象外です。バックグラウンドの確認はiOSの判断で行われるため、通知が必ず即時に届くわけではありません。

## 以前のファイルや一覧が消えた

毎年**4月1日・10月1日**の切替時は、学校データの再設定が必要です。[保存期間の説明](private-data-lifecycle.md)を確認してください。

## AltStoreでインストール・更新ができない

- iOS 27のPAL経由：[PC不要の導入・接続確認](altstore-pal-install.md)
- Windows経由：[AltServerの導入・署名更新](distribution.md)
- 無料Apple Accountでは通常7日以内に署名の**Refresh**が必要です。これはアプリの**Update**とは異なります。
- 更新が出ない場合は、AltStore ClassicのSource・更新一覧を再読み込みします。既存アプリを削除しないでください。

## 解決しない場合

[GitHub Issues](https://github.com/n624-dev/takupoke-ios/issues)へ、再現手順、期待した動作、実際の動作、**たくポケのバージョン・ビルド番号**とiOSバージョンを記載してください。バージョンは**設定 → このアプリについて**で確認できます。

**公開Issueには学校の実資料、OneDrive共有URL、氏名、メールアドレス、認証情報、個人情報を含むログ・画像を投稿しないでください。**
