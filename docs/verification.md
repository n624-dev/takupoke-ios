- 保存処理テスト、iOS ビルド、IPA・Source 生成は成功しました。
- Release の作成・添付後、一覧から同じタグの draft を再検索する処理で `Expected exactly one matching draft release` が発生しました。調査時には該当 draft が存在しましたが、直後の一覧に現れなかった理由までは確定していません。
- 作成APIの応答に含まれる Release ID を保持し、以降の操作を直接の ID で行うよう修正しました。アップロード、添付の読み戻し、最終公開にもタグからの再検索を使用しません。
- 新規 draft が一覧に一切現れなくても公開できる条件を回帰テストに追加しました。取得先不一致、添付不足・サイズ不一致、ダウンロード失敗時に公開を止める検証などを含め、ローカルの配布テスト24件が通過しました。
- 今回の実際の draft から4添付をID経由で読み取り、IPA・Source・メタデータ・SHA-256を照合しました。Release の状態は変更せず、取得用の一時ファイルは削除しました。

IDを使う操作は [GitHub Releases API](https://docs.github.com/en/rest/releases/releases) と [Release assets API](https://docs.github.com/en/rest/releases/assets) に基づきます。修正後の公開処理はCI確認待ちです。push後の監視は引き続き利用者が行います。

## 資料選択の実機報告とWeb取得への変更（2026-09-19）

利用者から修正版への更新完了と、以下の実機結果を受けました。更新対象の正確なversion / buildは未記録です。CIの監視は行っていません。

- OneDriveはフォルダ選択画面でグレーアウトし、選択できなかった。
- 個別ファイルは一度の操作で取得できる場合と、「ファイル」で一度開いた後に取得できる場合があった。
- この時点ではOneDriveの「オフラインで利用可能」は無効。オフライン設定による効果は未検証。
- 正式なアプリ表記は「たくポケ」。画面・ホーム画面名・AltStore Source・Release名・文書を修正する。
- 学校行事PDFは利用者指定の学校公式の固定URLから取得し、毎回取得せず端末内に保持する。

選択コールバック時にアクセス権を取得し、元URLの読み取りが成功した後でブックマークを保存する順序に変更しました。OneDriveは個別選択を主な導線にし、フォルダ選択は対応サービス向けの折り畳み項目にしています。この変更で未ダウンロード資料の取得が改善するかは実機確認待ちです。失敗原因をキャッシュと断定していません。

学校行事は初回取得後にアプリ専用領域へ保持し、手動更新でETag / Last-Modifiedを使います。304では保存済みのコピー・最終取得日時を維持し、最終確認日時だけを更新します。旧版の資料情報を読み込めることもテストしています。

このデバイスのSwiftテストは架空応答で、分割受信、200の保存、条件付きGET、304の保持、更新されたPDFへの置き換え、404・HTML・空応答・サイズ超過・取得中の中止と後片付けを確認しました。通信はテスト用URLProtocolで捕捉し、架空の想定URL以外も拒否します。CIや自動テストでは学校サーバーへ通信しません。

配信情報を確認する調査としてHEADを1回だけ実施し、PDF応答とETag / Last-Modifiedを確認しました。PDF本文は取得していません。利用者から実装上必要な調査としての取得は許可され、CI・自動テストからのアクセスは行わない方針を明文化しました。

Microsoft公式資料によるオフライン機能と「ファイル」連携の確認結果・制限は [学校資料の選択・取得](materials.md#onedriveの初回取得とオフライン設定) に記載しています。オフライン設定を必須条件や取得保証として扱いません。

本変更のiOSビルド・実機確認は未実施です。push後のCIの確認は利用者が行います。
