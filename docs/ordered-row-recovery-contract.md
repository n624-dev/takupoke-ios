# 限定した原行順による通常時間割の復旧

通常時間割の既存書式にある、セル内の科目・教員・教室という行順を使う。Strictを優先し、通常の復旧では独立した役割ラベルを確認する。この経路はラベルのない表を扱うための限定された追加経路であり、未知の書式の任意の3行へ役割を推測するものではない。

新経路では、全17クラス・5曜日・1〜8限の680コマを、原文の見出しと物理罫線から確認する。1時限・1物理セル・1授業・非空の3原行に限る。結合、並記、部分的な役割ラベル、欠落行をこの経路で補わない。

各原行の文字位置、原文、sourceLine、sourceOrderをアプリ生成の`orderedRowProof`へ保持する。文字単位の位置を持たないOCR行atomと、原行識別情報のない幾何fallbackは、この新経路では拒否する。既存の別経路には適用しない。

Validator 8は証明の原文ID・役割割当・セル所属・文字列の再構成・原行・文字順・元矩形を照合する。3行が縦に重ならないこと、文字の逆順や重なりがないこと、非空文字間の空間が隣接文字の高さの1.5倍を超えないことを要求する。大きい空間を明示空白文字で埋めても、左右複数塊の疑いを解消した扱いにはしない。この制限は未知の書式を受理するためではなく、対応できる書式を狭くする条件である。

全680コマの通常表で、固定した単一授業の科目・教員・教室が各1原行なら、任意の証明が欠けても縦順照合を行う。追加証明を旧Validatorへ遡及させない。旧版の採用記録は原本hash・結果hash・範囲hash・確認記録を照合し、現行Validatorで再検証できたものだけ引き継ぐ。検証できない場合も前回正常結果を破壊しない。

原文位置の架空入力テストは、認識エンジンの実測や完全なOCR文書の品質判定とは別に扱う。公開資料は独立した架空内容だけを使う。この実装は研究用分岐にあり、配布中のアプリへの適用には両OSの意味仕様とNative経路の検証が必要となる。
