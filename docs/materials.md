# 初期設定と学校ファイルの準備

初めて使うときは、**データの取得 → ファイルの選択 → 学校行事の取得 → クラスの選択**を済ませてください。アプリの初期設定画面から進めることも、設定画面から個別に操作することもできます。

## 1. OneDriveを準備する

学校から利用を認められたファイルを、iPhoneの**ファイル**アプリで開けるようにします。OneDriveを使う場合は、対象のファイルに対して**「オフラインで使用可能にする」**を選び、ダウンロード完了を確認してください。

「ファイル」アプリのブラウズ画面にOneDriveがない場合は、「場所」の編集から有効にします。OneDriveの同期には時間がかかることがあり、オフライン保存だけで常に最新版が保証されるわけではありません。

## 2. 学生向けデータを取得する

**設定 → リンク・名称・授業時刻**を開き、必要な項目を選んで**「学校アカウントで取得」**を押します。

- **リンク一覧**：学生向けサイトへのリンク。
- **名称データ**：科目・教員・教室の略称を正式名称で表示するためのデータ。
- **授業時刻**：日付ごとの授業開始・終了時刻。

名称データ・授業時刻を含む取得には学校のMicrosoftアカウントでの認証が必要です。リンク一覧だけなら、学内ネットワークでMicrosoft認証を省略できる場合があります。学外や判定できない場合はMicrosoft認証を利用します。

## 3. 時間割ファイルを選ぶ

**設定 → 時間割ファイル**を開き、次のファイルを選択します。

| ファイル | 形式 | いつ必要か |
| --- | --- | --- |
| 通常時間割 | PDF | 普段の授業を表示する |
| 時間割変更 | XLSX | 休講・補講・変更を反映する |
| 試験時間割 | PDF | 試験期間の予定を表示する |
| 試験返却時間割 | PDF | 試験返却期間の予定を表示する |

通常時間割と時間割変更を先に設定し、試験・返却ファイルは配布されたときに追加できます。選択後はアプリが自動で解析します。**「詳細を見る」**で取得・解析状況を確認でき、必要に応じて**「解析する」**で再試行できます。

## 4. 学校行事とクラスを設定する

**設定 → 学校行事**で対象年度を確認し、**「学校行事を取得」**を押します。初回取得は手動です。

**設定 → クラス**（または時間割タブの「クラス」）から表示するクラスを選びます。1年生は追加クラスも選択でき、留学生向けの授業表示も設定できます。

## ファイルは自動で更新される？

選択したPDF・XLSXは、アプリの起動時・復帰時などに変更を確認し、内容が変われば再解析します。ただし**OneDriveからiPhoneへ新しい内容が届くタイミングは保証されません**。

更新されない・読み取れない場合は、OneDriveで同期を確認し、iPhoneの「ファイル」で一度開いてから、たくポケの**時間割ファイル**で選び直してください。解析失敗時も、前回の正常結果があれば保持します。
