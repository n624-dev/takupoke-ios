# 学校資料の選択・取得

[README に戻る](../README.md)

ロードマップ②の開発版です。PDF・XLSXの取得と端末内保存を実装しています。内容の解析・時間割への反映はまだ行いません。OneDriveのフォルダ選択と再起動後の継続アクセスは実機確認待ちです。

## iPhone で使う

1. OneDrive アプリで学校資料へアクセスできる状態にし、iOS の「ファイル」でも資料を開けることを確認します。「ファイル」に OneDrive が出ない場合は、ブラウズ画面の場所の編集で有効にします。
2. たくぽけを更新して「学校資料を選ぶ」を開きます。
3. 「資料フォルダを選ぶ」で対象フォルダを選択します。直下の PDF・XLSX が候補になります。サブフォルダは探索しません。
4. 通常時間割・学校行事・時間割変更それぞれの「フォルダ内から選ぶ」で対応するファイルを指定します。ファイル名から用途を推測しません。
5. ファイル名、最終取得日時、取得済み・未解析の表示を確認します。提供される場合は元ファイルの更新日時も表示します。

File Provider がフォルダ選択に対応しない場合は、各資料の「PDF / XLSX ファイルを選ぶ」から個別に選択できます。通常時間割と学校行事は PDF、時間割変更は XLSX です。

## 再取得と再選択

- 「同じ資料を再取得」は保存したアクセス情報を使い、選択済みの資料をもう一度取得します。
- 再起動後も資料の状態は端末から読み込めます。フォルダの候補を再表示するには「フォルダ内の一覧を取得」を押します。
- この段階では起動・復帰時やバックグラウンドの自動取得は行いません。資料の更新後は手動で再取得します。
- フォルダを選び直しても、取得済み資料の参照先は自動変更しません。移行したい資料を新しいフォルダの候補から選び直してください。
- ファイル移動、アクセス失効、ブックマークの期限切れなどで取得できない場合は、資料またはフォルダを再選択します。別の資料へ推測で切り替えません。
- オフラインで再取得できるかは File Provider の端末内コピーの状態によります。オンライン時と同じ動作は保証しません。

## 制限・失敗時の動作

| 項目 | 現在の仕様 |
| --- | --- |
| 保存対象 | 3種類の資料につき1ファイル |
| サイズ | 1ファイル50 MiBまで |
| フォルダ一覧 | 非表示項目を除き直下1,000項目まで。上限超過は失敗として表示 |
| 除外 | シンボリックリンク、Excelの一時ファイル（名前が `~$` で始まるもの） |
| 形式確認 | 拡張子・空でないこと・PDF / ZIPの先頭識別子のみ。XLSXの構造や資料の内容は未検証 |
| 取得失敗 | 失敗を表示し、前回のコピー・参照先・取得成功日時を保持 |
| 中止 | 中止要求後に処理が戻った時点で終了。File Provider の応答により待つ場合あり |
| 保存情報の破損・コピー欠損 | 更新を停止し、既存ファイルを勝手に消したり初期化したりしない |

「取得済み」は読み取りと保存が成功した意味です。解析成功ではありません。今後の解析実装では、新しい資料の解析に失敗しても前回の正常な時間割を維持する必要があります。

## 保存・一時ファイル・プライバシー

資料のコピー、アクセス用ブックマーク、ファイル名、元の更新日時、取得日時、サイズ、SHA-256、直近の取得結果をアプリ専用の Application Support に保存します。現在は取得管理用の JSON とファイルであり、時間割統合用DBは後続の工程です。

取得途中のファイルは専用の staging に置き、読み取り成功後に保存先へ移動します。管理情報の原子的な書き込みを確定点とし、成功してから古いコピーを削除します。書き込みに失敗した場合は新しいコピーを除去します。途中終了した staging と未参照コピーは、次回「学校資料」を開いて保存情報を読み込む際に回収します。正常な管理情報を読み取れない場合は削除を行いません。

資料保存ディレクトリはバックアップ対象から除外し、iOS の完全ファイル保護を設定します。端末ロック中の利用は想定しません。元資料は読み取りのみで、アプリから変更・削除しません。File Provider 自身が持つキャッシュは管理対象外です。アプリを削除すると保存したコピーと設定も失われるため、元資料は OneDrive などで保持してください。

学校資料やアクセス情報を開発者のサーバーへ送る処理はありません。取得時の OneDrive との通信は File Provider が担当します。画面に表示するファイル名やフォルダ名には学校情報が含まれ得るため、公開 Issue へスクリーンショットを貼る際は伏せてください。エラー表示は固定文言とし、OSエラーに含まれるパスやアカウント情報を表示・ログ出力しません。

## 実機確認項目

以下は利用者による確認待ちです。公開の報告にはファイル名・学校名・内容を記載せず、成否と一般的なエラーだけを残します。

- [ ] OneDrive のフォルダを選べる。選べない場合は個別選択で取得できる。
- [ ] 2種類の PDF と時間割変更 XLSX が、それぞれ取得済みになる。
- [ ] アプリ終了・再起動後に保存状態が残り、同じ資料を再取得できる。
- [ ] OneDrive 側で資料を更新して再取得すると、取得日時と元の更新日時が反映される。
- [ ] 未ダウンロードの資料がオンラインで取得できる。
- [ ] オフライン・アクセス失効・元資料の移動時に、取得できなければエラーと前回の資料が残る。
- [ ] 資料を選び直して取得に成功すると、失敗表示が解消する。
- [ ] 中止後に再試行でき、前回の資料が保持される。
- [ ] 次のアプリ更新後も、資料の選択状態と保存情報が残る。
