# 学校ファイルと行事の取得

[READMEに戻る](../README.md)

通常時間割PDF・時間割変更XLSX・試験時間割PDF・試験返却時間割PDFは、iOSの「ファイル」から選びます。学校行事は年度を指定してAPIから取得します。

## 初回の取得

1. OneDriveで対象ファイルを開けることを確認します。「ファイル」の「ブラウズ」にOneDriveが表示されない場合は、場所の編集で有効にします。
2. たくポケの「設定」→「データ」→「時間割ファイル」を開き、4種類の各欄でファイルを選びます。試験・返却ファイルは必要なときに選択できます。
3. 選択後に取得・解析が自動で始まります。「詳細を見る」で結果を確認し、必要なら右上の「解析する」で再解析します。
4. 学校行事は「設定」→「データ」→「学校行事」で年度を確認し、取得します。期間・件数・取得日時・行事一覧は「詳細を見る」にあります。

ファイル一覧にはファイル名と短い状態を表示します。詳しいエラー、サイズ、取得・確認日時、元ファイルの更新日時、解析結果は詳細画面にまとめています。詳細で授業・変更・行事の数を表す項目名は「件数」です。

## OneDriveの準備

OneDriveで対象ファイルの「⋯」をタップし、「オフラインで使用可能にする」を選んで、ダウンロード完了を待ってください。iPhoneの「設定」→「一般」→「Appのバックグラウンド更新」でOneDriveを有効にしてください。低電力モードではバックグラウンド更新が停止し、同期が遅れることがあります。更新が届かない場合は、低電力モードを解除してOneDriveを開き、同期状況を確認してからたくポケへ戻ってください。

オフライン保存は読み取りの安定性を高めますが、クラウド上の最新版が即時に反映される保証はありません。取得できない場合は、「ファイル」で対象ファイルを開いてから再選択してください。

参照：[Microsoftのオフライン利用手順](https://support.microsoft.com/ja-jp/onedrive/read-files-or-folders-offline-in-onedrive-for-ios)、[Appleの低電力モード](https://support.apple.com/ja-jp/101604)。

## 選択画面と再選択

画面上部の専用欄に、選ぶファイルの案内を表示します。案内は初回選択・選び直し・フォルダ移動中も表示し、選択またはキャンセルで閉じます。周囲の背景は標準ファイル画面に合わせ、案内の角丸のガラス表示を維持します。

案内の文字量から必要な高さを測り、その下に標準ファイル選択画面を配置します。下方向へのスワイプやVoiceOverの「閉じる」アクションでもキャンセルできます。表示準備中の選択要求は保持し、キャンセル後の選び直しは前の画面が閉じてから開きます。

自動確認中にファイルを選んだ場合は、選択とアクセス権を保持し、処理終了後に選んだ順で取得・解析します。中止や半期切替時には待機中の選択も解除します。

ファイルの移動・アクセス失効などで読み取れなくなった場合は再選択します。通常時間割と時間割変更は、詳細画面の「同じファイルを再取得」も利用できます。

## 自動確認

4種類の選択済みファイルについて、起動時とアプリへ戻るたびに元ファイルを読み、SHA-256を比較します。内容が変わったファイルだけ再解析します。試験・返却PDFでは、解析バージョンが更新された場合も再解析します。旧版で再アクセス用情報を保存していない試験・返却の選択は、再選択後から確認対象になります。

- 表示中は`NSFilePresenter`で変更を監視し、`NSFileCoordinator`による読み取りを行います。短時間に届く通知はまとめます。
- 属性通知では識別子と内容の世代を比較し、同一と確認できた場合だけ読み直しを省きます。情報が不足する場合や内容変更の場合は、ファイルのSHA-256で確認します。
- 自身の読み取りには登録済みPresenterを関連付け、読み取り成功後に内容の世代を記録します。比較と記録を同じロックで保護し、通知による読み取りの循環を防ぎます。
- バックグラウンドへ移ると監視を解除し、復帰時に再登録・再確認します。起動・復帰時の確認は属性通知の省略判定の対象外です。
- 読み取り失敗時は確認失敗を表示し、前回の正常結果を保持します。

「最終取得」はファイルのコピーを保存した日時です。試験・返却PDFの内容が同じだった確認では「最終確認」を更新し、内容が変われば取得・解析後に両方を更新します。

「自動確認を中止」は時間割ファイル画面の右上にあります。実行中の取得・解析へ中止を要求し、待機中の確認と監視を停止します。選択・正常結果は保持します。別アプリへ移動して戻ると確認を再開します。File Providerの応答待ちにより、中止まで時間がかかる場合があります。

読み取りはFile Providerが提供する内容を対象とします。OneDriveがクラウド上の変更をまだ認識していない場合は、端末内の旧コピーを読む可能性があります。通知と同期の間隔はOneDriveとiOSの動作に依存します。

参照：[NSFilePresenter](https://developer.apple.com/documentation/foundation/nsfilepresenter)、[NSFileCoordinator](https://developer.apple.com/documentation/foundation/nsfilecoordinator)。

## 学校行事API

取得先は`https://takupoke-api.n624.jp/events?schoolYear=年度`です。現在は2026年度を提供します。応答の版・年度・日付・期間・タグ・元PDFのハッシュとETagを検証し、年度別に保存します。

初回は手動取得です。以後の起動時には保存済み年度をAPIのETagによる条件付きGETで確認します。304なら保存結果を維持し、200なら検証して更新します。ETagのない旧保存結果は通常のGETで更新します。通信失敗でも保存済み結果を残します。

APIのETagと`sourcePdfETag`は別の値です。起動時のAPI確認後、学校サイトの元PDFへHEADを送り、取得時の`sourcePdfETag`と比較します。差異・確認失敗は警告し、行事の表示を続けます。この確認でPDF本文は取得しません。ETag比較はSHA-256の再計算とは異なります。旧行事PDFの解析結果は時間割の表示元にしません。

タグの適用は[時間割の仕様](timetable-tab.md#学校行事api)、バックグラウンド確認は[通知・更新確認](notifications-background.md)を参照してください。

## 保存と失敗時の動作

| 項目 | 仕様 |
|---|---|
| 保存対象 | ファイルは種類ごとに現在の選択1件と最後の正常な解析結果。学校行事は年度別の検証済み結果 |
| ファイルの上限 | 1件50 MiB |
| 取得時の確認 | 拡張子、空でないこと、PDF・ZIPの先頭識別子。構造と内容は自動解析で確認 |
| 除外 | シンボリックリンク、`~$`で始まるExcel一時ファイル |
| 取得失敗 | 前回のコピー・参照先・取得成功日時を保持 |
| 解析失敗 | 新しい選択を保持し、前回の正常結果と失敗状態を表示 |
| 管理情報の破損 | エラーを表示して更新を停止。正常情報を読めない状態で既存ファイルを削除・初期化しない |

コピー・ブックマーク・元ファイルの情報・ハッシュ・解析結果をアプリ専用領域へ保存します。取得途中のコピーはstagingへ置き、保存確定後に未参照コピーを削除します。保存に失敗した新規コピーや途中終了した一時ファイルは、安全に管理情報を読める状態で回収します。

学校ファイルの保存領域はバックアップ対象から除外し、完全ファイル保護を設定します。半期切替時にはアプリ内の選択と保存結果を削除します。OneDrive上の原本は保持されます。詳しくは[保存設計](local-database-design.md)と[保存期限](private-data-lifecycle.md)を参照してください。

公開版には診断コピーの操作を表示しません。内部診断は[PDF解析仕様](pdf-specification.md#内部診断)を参照してください。

## 確認状況

個別選択・自動解析・再起動後の保持・更新確認の循環解消・キャンセル・OneDriveの実際の同期と選び直し・案内背景・半期切替時の削除について実機確認の記録があります。通信失敗、権限失効、未ダウンロード状態、OneDriveの検索・プレビュー、文字サイズ変更は条件ごとの確認が必要です。

版と確認範囲は[検証記録](verification.md)、架空データでの画面テストは[シミュレーター検証](simulator-verification.md)に記載しています。
