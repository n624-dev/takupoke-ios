# Strict PDFの互換性修正

基準は239.1（bfc599fd5a552ced0c140497c703199547c30fd4）。
380.1・今回の解析・AI／OCR OFFで通常P01、試験と返却P12が継続した報告に対応する。
全文差分は[固定コミットの監査](strict-pdf-diff-audit-239-380.md)へ残す。
実資料の実際の拒否分岐は未特定であり、以下を実機解消済みとは扱わない。

## 修正範囲

- Tr 1／2の一律拒否を撤回。元のUnicode・文字順・座標を保持し、
  埋め込みTrueTypeのPDFコード→GIDが明示できる場合は実glyphのpath境界、
  その他はFontBBoxと変換後の線幅、join／miterから別の描画範囲を作る。
  その範囲もページ・clipに入ること、罫線・塗り図形と重ならないことを確認する。
  不明なFontBBox、太い／破線の輪郭、不可視色、Tr 3〜7は受理しない。
  Tr2の白fillは、全glyphの字体範囲が分かり、他のglyphと重ならない場合だけ認める。
- Normalブレンドの単独名と1要素配列を同じ意味として扱う。
  代替が混在した配列や未知のブレンドは許可しない。
- 曲線は設定時の一律拒否をやめ、nで破棄された場合を許可する。
  実際に曲線を描いた場合の拒否を維持する。
- 有効な破線設定は保存・復元し、塗り文字に使わず上書きされた場合を許可する。
  破線を罫線や輪郭文字として採用しない。
- 幹が一意で文字と重ならない塗り矢印を、従来の検出器へ通す。
  任意の三角形や幅広の塗りは許可しない。
- Parser版を通常29・特別26に更新し、同じ内容SHAの旧失敗も再解析する。

## 維持する条件

ToUnicodeとPDFKit文字の照合、原文行・順序・セル所属、文書全体の構造検証、
年度の矛盾、日付・時刻の対応、空欄の役割と並記の曖昧性への拒否は維持する。
これらを外すと読めた文字を別の授業へ誤って割り当てる場合があるためである。
OCR／AIの呼び出し、確認UI、保存・取得、バックグラウンドの挙動は変更しない。

## 比較と確認

通常1ページ・試験6ページ・返却1ページを、それぞれ独立した架空の設計から生成する。
各設計にTr 0／1／2の3表現を用意する（3設計・9PDF・24ページ）。
輪郭の表現にはNormal配列、破棄される曲線、未使用の破線も含める。
元資料を入力・模倣せず、科目・教員・教室は明示的な架空値にする。
学校への通信はなく、生成器が取得するのはSHA固定の公開フォントだけである。

同じ生成PDFと同じ検査を239.1と現行のReader→Parserで実行し、
クラス・曜日／日付・時限・科目・教員・教室・授業数・時刻まで独立した正解と照合する。
古いコードへ追加するのは比較用テストの登録だけで、製品の解析条件は変えない。
現行では既存の不可視・重なり・破線・clip・曖昧なセルの拒否検査も実行する。
生成PDF・フォント・旧版の作業コピー・ビルドは所有する一時領域内で削除し、
Actions保存用artifactやキャッシュへ残さない。

CI成功と実機の3資料の改善は分けて記録する。
実行結果・失敗・対応根拠は[検証記録](verification.md)と[改善記録](ocr-improvement-log.md)へ残す。
