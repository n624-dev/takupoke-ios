# シミュレーター検証

実際の画面・解析・保存コードを使い、架空のファイルと解析結果で検証します。テスト用アプリの通信はすべて遮断します。

| 確認範囲 | 検証方法 |
|---|---|
| 通常・変更・試験・返却の解析、統合、時刻、連続カード | SwiftホストテストとPDFKit検証 |
| 前週・翌週・カレンダーの範囲、半期境界 | 週範囲のホストテストと画面操作 |
| ホームの今日の予定、授業詳細、カード配置 | 実アプリUIテストと共通スケジュールのホストテスト |
| 一覧の表示・個人設定の保持 | 実アプリUIテストと一覧・設定保存のホストテスト |
| 通常・変更・試験・返却ファイルの選択・キャンセル・選び直し | 実際のピッカーを使うUIテスト |
| ファイル更新・同じ内容・失敗・キャンセル・選択競合 | 更新確認・監視・保存のホストテスト |
| 規約・プライバシー文書・個別ライセンス | 実アプリUIテスト |
| 設定の分類、データ概要と詳細、学校行事、4種類のファイル詳細 | 実アプリUIテスト |
| 未取得時の入口、更新案内、取得・解析失敗時の前回結果保持 | 架空の保存状態・API応答による実アプリUIテスト |
| 使い方の5ページ、初期設定の各ステップ | 実アプリUIテスト |
| クラス共有、通知、メインカラー、リンクの開き方と再起動後の保持 | 実アプリUIテスト |
| 通知対象の絞り込み・差分・重複防止・本文 | 通知判定・履歴のホストテストとローカル通知の配信確認 |
| VoiceOverの授業読み上げ | iOS 27のVoiceOver操作テスト |
| 認証付き取得、revision、304、取得失敗時の保持 | モック通信と保存のホストテスト |
| 半期の削除、個人設定の保持 | 保存期間のホストテスト |

`tools/test-app-ui.sh`はiOS 26と27の専用Runnerで実行します。iOS 26はmacOS 26・Xcode 26.6、iOS 27はXcode 27を使います。指定OSのランタイムがなければ検証失敗とします。VoiceOver操作はXcode 27・iOS 27で実行します。アプリUIは専用のRunnerで実行します。ピッカーUIはホストテスト・配布ビルドと並列で実行します。
