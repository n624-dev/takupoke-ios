# iOS OCR acquisition completeness and cache safety

Source [`63ea9c8`](https://github.com/n624-dev/takupoke-ios/commit/63ea9c88212bfe6a3755743e9c6288ff7d62adfb) prevents an OCR recovery from silently omitting an entire printed class row. An independently invented two-class raster control reproduced the old adoption of only 40 of 80 slots while original pixels remained outside recognized cells. The existing full-page uncovered-ink check now applies to every OCR page; the complete control still recovers 80 slots and the omitted-row control refuses recovery.

The app binds a versioned page/dimensions/grayscale digest proof to the document scope fingerprint, including original source inventory and geometry. Old OCR caches without this proof require acquisition again; metadata migration cannot supply it. Stored previous results remain available with a warning. Legal vector acceptance timestamps and provenance remain unchanged. Parser version is 25; model schema 2, Validator 5 and field/structure prompt versions 4/3 remain unchanged.

[Checks](checks.json) records 352 successful final Linux tests, eight independent focused checks, 402 successful Mac tests, an iPhone SDK build and all seven required jobs in [run 37248116100](https://github.com/n624-dev/takupoke-ios/actions/runs/37248116100). UI26A initially passed 12 of 13 tests and failed a Settings selected-state wait. One authorized retry of that job, with identical source, assertions and timeouts, passed all 13; its original failure remains recorded and its cause remains unresolved. The other six successful jobs were not executed again. UI26B passed 12 tests with one documented skip.

This establishes acquisition-completeness and cache safety, not literal OCR accuracy or model qualification. The independently generated vector fixtures' separate Strict 680-slot results, Validator/cache tests, and UI configuration/save checks are distinct evidence. No model or OCR request was added by this production change, and no unqualified model was enabled. The school PDF was used only for private understanding by the parent agent, then deleted; it and its names were never inputs to these generators, tests or CI. All test values are fictional. This directory contains source-level summaries only, with no PDF, font, PNG or image payload. Publishing these two report files adds no CI/native execution.
