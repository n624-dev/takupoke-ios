# たくポケ iOS

**たくポケ**は、香川高専詫間キャンパスの学生向けに個人が開発・運営している、iPhone用の**非公式アプリ**です。学校・高専機構が運営、承認、推奨、保証するものではありません。

時間割やその変更、試験・試験返却の予定、学校行事、学生向けリンクを、ひとつのアプリで確認できます。

> **重要**：表示内容は元資料の解析や外部サービスの更新状況により、誤り・遅れが生じることがあります。休講、試験、提出期限などは、必ず学校の公式案内・元ファイルでも確認してください。

## できること

- **ホーム**：今日の授業・行事、お気に入りリンク、データの更新案内を確認する。
- **時間割**：クラスと週を選び、通常時間割・変更込みの予定・試験・返却予定を確認する。
- **一覧**：学生向けリンクを検索し、お気に入り、色変更、非表示などを設定する。
- **更新と通知**：選択したファイルの変更を確認し、設定した種類の更新をiPhoneに通知する。

通常時間割PDF、時間割変更XLSX、試験時間割PDF、試験返却時間割PDFをiPhone内で解析します。学校行事は配信APIから取得します。

## インストール

対応端末は **iOS 26・27のiPhone** です（縦画面で使用します）。App Storeからの直接インストールではなく、**AltStore Classic**を使って導入します。

- **iOS 27・日本国内で、PCを使わず導入する**：[AltStore PALからインストール](docs/altstore-pal-install.md)
- **Windows PCから導入する（iOS 26でも可）**：[AltServerを使ったインストール](docs/distribution.md)

[最新の公開版（GitHub Releases）](https://github.com/n624-dev/takupoke-ios/releases/latest)

AltStore Classicに追加する**たくポケのSource URL**：

```text
https://github.com/n624-dev/takupoke-ios/releases/latest/download/altstore-source.json
```

無料のApple Accountで署名したアプリは、原則として**7日以内にRefresh（署名更新）**が必要です。アプリの署名更新と、新しいバージョンへのアップデートは別の操作です。

## 最初にすること

1. OneDriveで学校の時間割ファイルを開けるようにし、可能なら「オフラインで使用可能にする」を選びます。
2. たくポケの**設定 → リンク・名称・授業時刻**から必要なデータを取得します。名称データ・授業時刻には学校のMicrosoftアカウントでの認証が必要です。
3. **設定 → 時間割ファイル**で通常時間割PDFと時間割変更XLSXを選びます。試験・試験返却PDFは必要になったときに追加できます。
4. **設定 → 学校行事**で年度を確認して取得し、**設定 → クラス**で表示するクラスを選びます。

初期設定画面の「あとで設定」を選んだ場合も、後から**設定 → 初期設定**で再開できます。

[初期設定とファイルの準備](docs/materials.md) · [時間割の見方](docs/timetable-tab.md) · [リンクの使い方](docs/links-tab.md)

## 更新・保存について

選択済みの学校ファイルは、アプリ起動時・復帰時などに更新を確認します。ただし、OneDriveやiOSの同期・バックグラウンド実行により、反映が遅れる場合があります。

**毎年4月1日・10月1日の切替後**は、アプリ内の学校ファイル、解析結果、取得した学生向けデータなどを削除します。ファイルの再選択と再取得が必要です。クラスやお気に入りなどの個人設定、OneDrive上の原本は保持されます。

[更新と通知](docs/notifications-background.md) · [データの保存と削除](docs/private-data-lifecycle.md)

## 困ったとき・問い合わせ

不具合や改善提案は[GitHub Issues](https://github.com/n624-dev/takupoke-ios/issues)へ。学校の実資料、氏名、認証情報、個人情報を含むスクリーンショットやログは**公開しないでください**。個別の問い合わせ先はアプリ内の「このアプリについて」で確認できます。

利用規約とプライバシーポリシーは**設定 → このアプリについて**から読めます。プロジェクトのソースコードの利用条件は、別途ライセンスが明示されていない限り、自由な再利用を認めるものではありません。
