# たくポケ

学校の時間割・時間割変更・試験・試験返却・学校行事を、iPhoneで確認できるアプリです。

> **ご注意**: 個人開発・運営の非公式アプリです。試験や休講などの重要な予定は、必ず学校の公式案内や元の配布ファイルもあわせて確認してください。

[インストール手順](docs/altstore-pal-install.md) · [最新リリース](https://github.com/n624-dev/takupoke-ios/releases/latest) · [困ったとき・ファイル準備](docs/materials.md)

---

## 対応環境

- **対応端末**: iOS 26・27 搭載の iPhone（縦向き専用）
- 標準の Liquid Glass デザイン、OSの文字サイズ拡大、VoiceOver に対応しています。

---

## 主な機能

- **時間割・試験の自動解析**: 通常時間割（PDF）・時間割変更（XLSX）・試験時間割（PDF）・試験返却時間割（PDF）を選択すると、自動で解析して端末内に保存します（※1年次のPDF授業で科目名に「CN・ES・IT」のいずれかが明記されているものは、該当する学科へ自動で振り分けられます）。
- **週の時間割表示**: 学校行事や時間割変更を組み合わせた週間カレンダー。画面の左右端を引いて離すと前週・翌週へ滑らかに移動でき、通常／変更込みの切り替えや連続授業の結合に対応しています。変更一覧では科目・教員・教室の差分を、詳細では理由と更新日時を確認できます。
- **ホーム＆カウントダウン**: 今日の予定（科目の正式名称を優先表示）やデータの更新案内を確認できます。学校行事・自分の予定・試験のカウントダウンをホームに最大3件表示でき、日本時間での通知予約も可能です（[カウントダウンの使い方](docs/countdown.md)）。
- **学内リンク・シラバス連携**: リンクの検索・お気に入り・色変更・非表示のほか、開くブラウザ（アプリ内／標準ブラウザ）を選べます。設定で「シラバスの学科」を選んでおくと、選択学科・当年度のシラバスをすぐに開けます。
- **自動更新確認・通知**: 起動・復帰時やバックグラウンドで更新を確認し、選択中クラスの時間割変更や試験・返却PDFの更新を通知します。一時的に取得・解析に失敗しても、保存期間内は前回の正常データを保持します。
- **カスタマイズ**: OS標準＋7色から選べるメインカラー、留学生向け授業の表示／非表示切り替えに対応しています。

## インストール・アップデート

お使いの iOS バージョンに合わせて導入してください。

1. **iOS 27 以降（AltStore Classic 2.3 以降）の場合**  
   **AltStore PAL → AltStore Classic → たくポケ** の順に導入します（デベロッパモードの有効化と再起動後の確認が必要です）。詳しい手順は **[インストール手順（AltStore PAL経由）](docs/altstore-pal-install.md)** を参照してください。
2. **iOS 26 など上記条件に当てはまらない場合**  
   PCを使用する **[WindowsのAltServerを使う手順](docs/distribution.md#windows-と-iphone-の準備)** を利用できます。

**AltStore Classic に追加する Source URL:**

```text
[https://github.com/n624-dev/takupoke-ios/releases/latest/download/altstore-source.json](https://github.com/n624-dev/takupoke-ios/releases/latest/download/altstore-source.json)
```

### アップデートと署名更新について
- **新しい版へのアップデート**: AltStore Classic の Source／更新一覧を更新するとアップデートできます（Source の再登録やアプリの削除は不要です）。[Releases](https://github.com/n624-dev/takupoke-ios/releases/latest) からも最新版を確認できます。
- **署名の有効期限更新**: 無料の Apple Account を使っている場合の「署名更新」と「アプリのアップデート」は別の操作です。詳しくは [配布の仕組み](docs/distribution.md) を参照してください。

## はじめかた・設定メニュー

初回起動時の案内に沿って、**①学校アカウント認証 → ②時間割ファイルの選択 → ③クラスの選択** を行います。手元にないファイルは「あとで設定」を選んで後から追加できます。

アプリ内の「設定 → サポート → 使い方」から、目的別の5ページガイド（「はじめに」「時間割を見る」「リンクを使う」「更新と通知」「困ったとき」）をいつでも確認できます。

| 設定分類 | 項目とできること |
| --- | --- |
| **データ** | **時間割ファイル**: 4種類のPDF・XLSXを選択して自動解析（「詳細を見る」から件数確認や再解析が可能）<br>**学校行事**: 年度を確認して取得（元PDFとの差異や長期未確認がある場合はホームや週画面に案内を表示）<br>**リンク・名称・授業時刻**: 一覧・正式名称・授業時刻をまとめて取得（初回一括や名称・時刻は Microsoft 認証、リンク一覧のみなら学内ネットワーク認証にも対応） |
| **アプリ設定** | **クラス**（時間割画面からも変更可／留学生向け授業の切り替えもここ）、**通知**、**メインカラー**、**リンクの開き方**、**シラバスの学科** |
| **サポート** | **初期設定**、**使い方**、**このアプリについて**（規約・ライセンス確認） |

※ 取得・確認・解析・元ファイル更新の日時は、端末のタイムゾーンにかかわらず**日本時間**で表示されます。  
※ OneDrive の同期状況によって読み取れるファイルの版が異なる場合があります。うまく反映されないときは [ファイル選択と取得](docs/materials.md) を確認してください。

## うまく読み取れない・内容を修正したいとき

- **時間割変更（XLSX）を手動で修正する**  
  「設定 → 時間割変更 → 内容を確認・修正」から、学年の空欄補完、日付からの曜日補完、学年・クラスの一括入力、不要な行の除外を端末内で行えます。元の資料が更新されても、元の行全体が一致する箇所には修正が自動で引き継がれます（「修正済み」から見直し可能）。
- **PDFの解析に失敗する場合（端末内 AI・OCR 復旧 ※開発中）**  
  初期設定では誤読を防ぐため「AI・OCRを使用する」は OFF になっています。ON にすると、通常の厳格な解析に失敗した PDF のみ端末内で復旧を試みます。復旧後のプレビューで科目を長押しすると、元PDFと照合して科目・教員・教室を訂正できます（資料全体で最大3項目まで）。
- **試験返却PDFの表示崩れを開発者へ相談する**  
  返却PDFで見出し混入などがある場合、解析結果の授業詳細から「位置情報を取得」→「位置情報をコピー」を操作してください。授業名・教員名・教室名・画像などの非公開情報を含まない位置データだけをコピーして共有できます。

## データの保存期間とプライバシー

### 学期切り替え時の自動リセット（4月1日・10月1日）
日本時間の **4月1日** と **10月1日** の切り替わり後に、端末内の非公開データ（学校ファイルのコピー・解析結果・アクセス用ブックマーク・リンク一覧・名称データ・授業時刻）は**自動的に削除**されます。新学期にはファイルの再選択とデータの再取得を行ってください。

- 選択したクラスやお気に入りなどの個人設定、公開の学校行事、OneDrive 上の元ファイル自体は削除されません。詳しくは [非公開データの管理](docs/private-data-lifecycle.md) を参照してください。

### プライバシーとライセンス
- 学校ファイル・アクセス用ブックマーク・解析結果はすべて端末内のみに保存され、iOS のファイル保護を適用したうえでバックアップ対象から除外しています。外部へ学校の実資料や個人情報が送信・公開されることはありません。
- 使用しているオープンソースソフトウェアのライセンス全文は、アプリ内の「設定 → このアプリについて」から確認できます。
